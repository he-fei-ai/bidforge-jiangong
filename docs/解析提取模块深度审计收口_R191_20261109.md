## 二、现状分析（模块架构速览）

- **服务层** `backend/app/services/file_parser.py`（~2100 行）：16 格式解析分派
  （`parse_file_content_ex`）+ `_decode_text_ex` 编码链 + `_BINARY_SIGNATURES` /
  `signature_valid` 文件头校验 + 压缩炸弹四闸门（R112 环境变量化）+ `_OUTLINE_PATTERNS`
  目录识别正则 + PDF OCR 兜底（`_pdf_ocr_fallback`）+ 多页 TIFF 拆帧
  （`_split_tiff_frames`）+ `simple_parse_outline` 栈式建树。
- **分类** `backend/app/services/doc_categories.py`：`AUTO_CLASSIFY_RULES`（10 类，
  顺序即优先级）+ `EXTRACT_PRIORITY`（AI 提取合并读取序）+ `auto_classify_document`。
- **路由层** `backend/app/routers/global_facts_docs.py`（~1800 行）：8 端点
  （upload-documents / parse / parse-all / preview / category / category-options /
  delete / list）+ `_persist_parse_result` 唯一落库口径 + `_doc_parse_guard`
  逐文档并发锁 + `_mark_project_facts_stale` / `_invalidate_project_export_caches`
  下游失效。
- **存储** `backend/app/services/doc_pipeline/`：四层存储（原文/解析/提取/语义）+
  `documents_index.json` 归档索引 + `doc_chunker`（section/semantic/table 三类块）。
- **跨模块消费链**（本轮全景核对）：目录生成 `load_parsed_texts(limit=5)`、正文
  生成 `load_parsed_texts(limit=3)`、事实提取 `_load_facts_source_docs`、18 项结构化
  提取（bid_analysis 四信号 parity）、评分项提取（scoring_items）、一致性扫描
  （consistency_scanner）。
- **前端**：UploadParseTab（上传/批量解析状态机）+ DocumentParseList（行内操作）+
  useDocumentWorkflow（hook 编排）+ uploadAccept（白名单/配额预检单一口径）+
  DocumentPipelineSummary（四层产物可视化）。

## 八、教训归档

1. **回溯命中是新 pattern 的头号杀手**：`^(\d+(?:\.\d+)+)\s*[、.\s]\s*(.*)` 对
   "1.1.1X" 会回溯吃掉最后一段再命中——更具体的无分隔符 pattern 必须排在它
   **前面**，排在后面永远轮不到（正则 alternation 顺序纪律）。
2. **长 BOM 优先**：\xff\xfe\x00\x00 以 \xff\xfe 开头，UTF-32 BOM 条目必须排在
   UTF-16 之前，否则前缀匹配抢判（编码表顺序纪律）。
3. **SQL 条件拼接必须在 ORDER BY 之前**：追加到 ORDER BY 之后 SQLite 会解析成
   排序布尔表达式，过滤静默失效且**无语法错误**（护栏首跑抓获）。
4. **函数级测试对调用点键位错位全盲**：A/B 变异调用点实参时，测函数行为的护栏
   全绿——「源码锁必须锁调用点而非只锁定义」第三次实证（R148 属性式调用 /
   R187 M8 摘 env= / 本轮 M9）。
5. **python 脚本 write_text 是行尾杀手**：`read_text`（universal newlines）+
   `write_text(newline="")` 把 CRLF 文件全文件 LF 化（doc_storage.py diff 876 行
   全是行尾漂移）——脚本改文件前必须先探测原行尾（R161 教训复现，本轮体检
   抓获并还原）。
6. **Windows subprocess 调 npx 必须 ["cmd","/c","npx",...]**（npx 是 .cmd）；
   heredoc 内含 `\n` 字面量的替换脚本会转义衰减，改用 chr(10) 或 Edit 工具。
7. **静态锁须覆盖赋值链**：M11 首跑 MISSED——只锁渲染三元表达式时，摘除数据
   赋值仍静态通过（「后端回传字段前端零消费」教训的前端渲染侧变体）。
8. **统一口径前先核对列是否存在**：B3 修复首版给 base SQL 加 text_len——而
   project_documents 根本没有该列（统一口径的长度兜底按 len(parsed_markdown)
   回推），真实库虽不崩（异常路径兜住）但测试 fixture 立即 3 红；修法=撤销加列、
   只改判定出口。「对齐上游实现」不等于「照抄上游 SQL 列集」。
