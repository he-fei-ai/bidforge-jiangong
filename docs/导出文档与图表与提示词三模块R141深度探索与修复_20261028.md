## 三、缺陷修复（1 项，证据支撑）

### 3.1 【FIX-1 · LaTeX→OMML 幽灵空 run 清理（P3，`docx_math.py`）】

**现象（探针实拍，`_r141_probe_ghost.py`）**：
- `\text{}` → `<m:r><m:rPr><m:sty m:val="p"/></m:rPr><m:t xml:space="preserve"></m:t></m:r>`（幽灵空 run）
- `\mathrm{}` → 同上
- `\frac{a}{\text{}}` → `<m:den><m:r><m:t></m:t></m:r></m:den>`（空 den 被「伪装」成元素级非空）

**根因**：`_parse_seq`（`docx_math.py:565-570`）与 `_parse_atom`（`:674-678`）对 `text/mathrm/operatorname/mbox` 空内容组装 `("op", "")`，`_node_to_omml` 的 `_r("")` 产出空 `<m:t></m:t>`。

**影响**：① 语义空洞（一段不可见数学内容）；② 绕过 R122 空参防护网（后者只查 `<m:num></m:num>` 元素级空，而 `<m:den>…空 run…</m:den>` 元素级非空）—— 这是 R128 留痕「幽灵 token 清理」建议的落地。

**修复**（`docx_math.py`，加法式）：
- `_parse_seq`：空内容 `txt` 不 `append("op","")`，直接 `continue`（跳过）。
- `_parse_atom`：空内容返回 `("seq", [])`（渲染为空串），不产空 run。

**行为说明**：
- 非空 `\text{式中：}` / `\mathrm{MPa}` 等**逐字不变**（探针实证 `式中` 保留）。
- 空 `\frac{a}{\text{}}` 的 den 变回真正为空 → R122 防护网接管 → **回退**（图片或源码文本，由环境决定），与 `\frac{a}{}` 同一一致性口径。
- `\sum_{}` 空被和式的空参 run **刻意保留**（R126 FIX-C2 形态，schema 非空 CT_OMathArg 必需，D 组护栏锁定，不属本修复范围）。

**验证**：
- 新护栏 `backend/tests/test_r141_omml_ghost_run_20261028.py`：**16 passed**。
- docx_math + export + WPS 簇（9 文件）：**262 passed / 0 failed**。
- 全 chart/export/prompt 簇回归：**1612 passed / 12 skipped / 1 xfailed / 0 failed**（与基线逐字一致，零回归）。
- `ruff` 改动文件：**All checks passed!**。
- 字节体检：无 BOM、纯 LF（`docx_math.py` 1073 LF-only；新护栏 154 LF-only）。

## 九、判据教训归档（本轮）

1. **「空参伪装」是 R122 防护网的盲区**：R122 只查 `<m:num></m:num>` 元素级空，而 `<m:den><m:r><m:t></m:t></m:r></m:den>` 元素级非空、绕过防护 —— 探针实拍证明，非理论推演。
2. **降级路径由环境决定，测试只锁不变量**：`\frac{a}{\text{}}` 的落盘形态（matplotlib 图片 vs 源码文本）依赖环境，护栏应锁「无空 m:den + 无幽灵 run」这一不变量，而非特定降级分支。
3. **空 `\text{}` 族是「可复现的确定性缺陷」而非「理论担忧」**：直接单测即可复现，无需复杂编排。
4. **并行会话活动区（schema_sql/observability）不越界**：观察到的 P0 SyntaxError 属并行会话 in-flight，只留痕不干预，避免写入冲突。
5. **改动文件字节体检**：BOM/行尾须与既有约定一致（LF），`-Encoding ASCII` 会破坏中文路径（`?` 占位）导致 cmd 启动的 pytest 收集 0 项 —— 改用 PowerShell 启动 + UTF8 脚本。
