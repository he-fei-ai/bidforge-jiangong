- **需重启后端**（export/_export_cache/_export_issue_scan/_export_docx_parts/docx_math/content_blocks/facts_extractor 常驻）；**前端需重建**（fencePreprocess/MarkdownRenderer/exportResponse/useExportRun/useExportPresets/exportCharts/DossierExportCard）。

- **效果复算锚**：昨日导出成功 → 今日渲染服务挂 → 今日导出缺图降级 → **昨日好产物保留**、下次服务恢复命中好产物（旧实现：残缺版顶替且零信号）；含「A、B 两案对比」的章节导出 → 首字母保留（旧实现被删）；`$p = 50\%$` → 公式内无反斜杠；`\begin{pmatrix} a & b \\ c & d \end{pmatrix}` → 真矩阵（Word 公式编辑器可二次编辑）；`\frac{\sigma_{max}}{f}` → 下标语义保留；「详见下表」不再被吞进表题；含 `C:\Users\new` 正文的导出不再永久降级；正文含 U+FFFE 的段落不再整块消失；导出成功 toast 同步显示体检命中与预检失效提示；预设加载失败有提示；Firefox 底稿下载不再偶发失败。

## 十、教训归档

1. **轮次号占用检查必须在「落地前」再跑一次**——开场 grep R226 未占用，数小时后并行会话报告落盘即撞号；批量让号（67 处 + 文件改名）成本低但全量回归必须重跑（中途改名让首跑结果失真）。
2. **「无条件丢弃重复行」必须先问「这行有没有可能是数据」**——B12 首版无条件丢弃 nxt_lines[0] 被 R179 回归护栏当场抓红：该场景后随表无表头，首行是数据行；改成条件丢弃（逐格相同才视为重复表头），「宁多勿丢」。
3. **clean_text 类「链式清洗函数」插步骤时不得提前 return**——B2 补口首版把终末剥离+return 插在函数中段，西里尔/表格标记降级/Markdown 转义还原等 6 项既有修复变成不可达代码；当场发现回滚重做（补口必须挂在真正的出口处）。
4. **护栏自证的「实测通过」要用与被测代码相同的求值路径**——B4/B5 在 `python -c` 里 shell 转义吃掉一层反斜杠（`\\begin` 变 `\b`→退格），产品代码正确而探针误报；用文件方式（heredoc 或 Write）求值才可信。
5. **前端跨端护栏读后端源码不可行**（vite fs.allow 拒绝 root 外 ?raw，Denied ID 实测）——parity 双向锁拆成两侧各自护栏 + 前端锁头名镜像。
6. **`_EXPORT_*` 全局是 dict 还是 set 要以实际定义为准**——conftest 隔离 fixture 首版按代理报告写 set，`_ZIP_VERIFIED` 实为 dict（tuple 键记忆化）。
