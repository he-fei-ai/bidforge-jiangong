5. 按需渲染：导出 DOCX 时实时渲染；优先级 fe PNG > hifi 模板轨 > get_or_render（mermaid.js / PIL）。

## 三、本轮定罪与落地（唯一实质代码改动）

**缺陷**：`hifi_charts.exporter.render_hifi_png` 此前绕过 ChartCache —— 同载荷重复导出反复 launch Playwright（每图 ~1-2s）；`export._render_one` 在事件循环上被 `Semaphore(4)` 并发 gather，同图并发无共享去重。

**改动文件**
- `backend/app/services/ai/hifi_charts/exporter.py`（+144/-14）：
  - 新增 `_HIFI_CACHE_VERSION`、`_LOGGER`、`_hifi_cache_key(route, payload, scale_preset)`（复用 `ChartCache._cache_key`，命名空间 `hifi:{route}:{scale}`，与 mermaid 轨键空间隔离）。
  - 新增 `_HifiRenderGate`：磁盘缓存（独立子目录 `charts/hifi`，不挤占 mermaid LRU 配额；读用 `asyncio.to_thread` 不占 loop；坏字节 `_cached_bytes_ok` 校验失败删文件重渲自愈）+ asyncio 单飞门（同 key 并发只起一个渲染 task，其余共享结果；跨事件循环重起）。
  - 模块单例 `_hifi_gate`、公开 `get_hifi_render_stats()`（键 `cache_hits`/`cache_misses`/`inflight_shared`/`cache_errors`；`cache_misses`=leader 真实渲染次数，`inflight_shared`=共享去重次数）。
  - `render_hifi_png` 重构：TTL 短路后算 key，闭包 `_render_once` 经 `_hifi_gate.render` 单飞，门外 `_put` 写缓存；缓存初始化失败降级为无缓存（渲染照常）。
  - `__all__` 加 `get_hifi_render_stats`；`import logging`。
- `backend/tests/test_chart_hifi_cache_r249_20261115.py`（新增 11 例）：A1 磁盘 round-trip / A2 scale 隔离 / A3 路由载荷隔离 / B1 单飞共享 / B2 单飞传播失败 / C1 坏缓存自愈 / C2 TTL 优先于缓存 / D1 无缓存降级仍渲染 / D2 无缓存仍单飞 / E1 公开面+键命名空间 / E2 stats 快照隔离。

## 五、优化项清单

1. hifi 渲染磁盘缓存（同载荷重复导出从 ~1-2s 降到毫秒级）。
2. hifi 同图并发单飞去重（4 并发 `inflight_shared=3`、唯一产物 1 份）。
3. 缓存读放线程池，不阻塞事件循环。
4. 坏缓存自愈（截断/半文件删除重渲），与 mermaid 轨同向。
5. 缓存目录只读 ACL 下降级为无缓存，渲染永不因缓存失败。
