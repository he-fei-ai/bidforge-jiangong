### 1.4 三模块贯通链（实测）

```
资料 ──► 事实抽取/落库 ──► global_facts
                             │  门控：_FACTS_INJECT_WHERE（四档 fail-closed）
                             ├─► 正文注入（facts_builder）──► 正文生成 ──► normalize_section_content_subheadings
                             │        │                              └─► content_actually_changed（唯一判据）──► 落库 word_count
                             │        └─► 上下文装配（content_runtime 任务差异段）
                             ├─► 预检桥接（load_resolved_facts_for_scope）──► ctx.facts
                             │        └─► check_hazard_params（SAF-08 事实反哺危大判定）
                             ├─► 审核 / 合规 / 一致性修复（同一门控）
                             └─► 底稿「事实待确认」（dossier，口径 = 门控补集）

正文 ──► 预检 check_completeness（finding 带 section_id）──► 合规总检 ──► 导出预检
                                                              （LOW_WORD_THRESHOLD 与预检同源）
```

**本轮贯通专项实测结论**：这条链是**通的**，但「通」此前**没有任何一条护栏覆盖** —— 三个模块各自全绿，仍可能在接缝处静默断裂（例如事实被门控排除后既不进正文、也不进预检、更不进复核清单）。已由 §五 的 8 条跨模块护栏钉住。

## 十、教训归档

1. **「各自全绿」不等于「链通了」**：三模块各自有护栏、簇全绿，但**跨模块接缝零覆盖** —— 事实被门控排除后是否还进复核清单、章节 id 是否从预检一路带到修复侧、阈值是否在预检/导出两侧同源，**没有任何一条护栏管**。本轮补 8 条贯通护栏后，才第一次有「链」的证据。
2. **同一判据两份实现 + 同族漏改，是本仓的病根形态**：基号解析（R212）、阈值（R212）、severity 色板（R212）、覆盖度搬运（R212）、正文变更判据（R211）、布尔归一（R211）、来源类别（R210）、冲突回写（R210）—— 统一以「**唯一事实源 + 全部调用点一次收口 + 棘轮防回流**」根治。
3. **注释里的字面量也会污染字节体检**：R212 护栏文件的注释里出现 2 个 U+FFFD（替换字符）—— 不影响任何断言，但会在字节体检里被抓出来；**字节体检必须每轮做**，且要覆盖**本轮新增的测试文件**（不只生产源文件）。
4. **行尾的权威来源是 `.gitattributes`，不是「文件当前长什么样」**：本仓 2026-11-08 起规定 `*.ts` / `*.tsx` / `*.md` 一律 `eol=lf`（前端源码与文档统一 LF）。本轮实测：两个前端文件的工作树副本被翻成 CRLF（HEAD 是 LF），且 **R199 的字节护栏把「行尾不得漂移」锁成了历史残留的 CRLF 期望值** ⇒ 照着护栏改反而错。**既有护栏红先问「锁意图还是锁实现」**：此处意图是「不得漂移、随仓库规范演进」，实现是「必须是 CRLF」⇒ 重锚为 LF（与 HEAD + `.gitattributes` 逐字一致），意图保留、**强度不减**（不再容忍任一方向的漂移）。行尾必须**拿 HEAD 与工作树逐文件比对**才看得出来，不能假设编辑工具不动行尾。
5. **前端未装 `@types/node` ⇒ `node:fs` 直接让 `tsc` 红**：R212 前端护栏用 `node:fs` 做源码棘轮，后端跑 `TestFrontendRealExecution` 时被 tsc 抓出（TS2307）。前端读源码应走 **vite `?raw` 导入**（不执行被读模块、类型由 `vite/client` 提供、零新增依赖）。
6. **反证比正例更能防假绿**：CHAIN-2 用「同一行事实从可注入变成过期」做**正反两次**断言（先证不落库、再证不进预检）；CHAIN-4 追加「无改写时必须判为未变」，防止判据被做成恒真。
7. **「唯一命中才填，宁可空缺不可错配」**：R212 FIX-E 的标题反查章节 id 刻意**不猜**（同名多章返回空串）—— 与「限一片」的修复侧策略配合，才能既不张冠李戴、又不凭空造 id。
8. **并行会话会撞轮次号**：同一工作树上两个 R210 已实际发生 ⇒ 开跑前除 grep 轮次号外，还要确认**同号是否被别的模块占用**，历史报告排除清单按**模块名**筛。
