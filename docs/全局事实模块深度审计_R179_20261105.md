## 3. R179 修复项清单（已落地并验证）

### BUG-R179-01（P1）AI 调整计划内重复 `add` 未被拦截 → 同 key 双值可同时注入

- **改了什么**：`_validate_adjust_ops` 接受一条 `add` 后把归一化键写回 `existing_keys`（`global_facts.py` L2978）。
- **为什么**：旧实现只比对「既有事实键」，校验完成后从不回写本计划新增键。实测（修复前导出该函数）：`add 项目经理=张三` + `add 项目经理=李四` 返回 **2 条** ops；`adjust_facts` 逐条落库后两份均 `has_conflict=0 AND is_resolved=1`，同一事实两个取值同时进正文与导出。
- **如何验证**：`test_r179_validate_adjust_ops_drops_duplicate_add_within_plan`；删除该行后用例必红（已做变异验证）。
- **测试结果**：通过。

### BUG-R179-02（P1）手工新增同名事实可绕过冲突门控 → 两条取值同时注入

- **改了什么**：新增 `_norm_dup_value` / `_filter_create_fact_duplicates`（`global_facts.py` L1248/L1254），在 `create_fact` 落库前（L1359）做同名守卫：
  - 同名同值 → 幂等去重（不新增行，返回既有分组 id，响应加法式带 `deduplicated`）；
  - 同名不同值 → **409** 并提示直接编辑既有条目，整组事务回滚；
  - 作用域与注入口径一致：方案级 = 本方案私有 + 项目共享；项目级 = 仅项目共享，不误伤其他方案私有同名事实。
- **为什么**：R175 §9 只修了「调整」读口径与 AI 路径，`POST /global-facts` 手工写入没有任何同名比对；手工事实默认 `is_resolved=1`，与已确认抽取事实同 key 不同值时两条都满足注入门控。
- **如何验证**：5 条回归覆盖不同值 409、同值去重、组内重复、跨作用域（项目共享可见 / 他方案私有不可见）、模拟值标记不参与比较。
- **测试结果**：全部通过。
- **兼容性**：只在「同名已存在」场景产生新行为；无同名时与旧逻辑逐字节等价；响应仅新增字段。

### BUG-R179-03（P2）附录「项目关键事实」第二列仍重复事实名称

- **改了什么**：`_export_docx_parts.py` 新增 `_strip_leading_fact_name`（L277），`_appendix_cell_paragraph` 增参数 `strip_name`（L296/L317）；`export.py` 两处调用点传入名称（L3287/L3336）。
- **为什么**：R175 BUG-09 只修了第二列的 Markdown 源码残留（`- **名称**: 值` 的 `- `），名称仍在第一列标题 + 第二列取值中重复出现。
- **如何验证**：`test_r179_appendix_strip_leading_fact_name`（含正则元字符名称、名称非行首不误删）、`test_r179_appendix_cell_paragraph_no_duplicate_title`（成稿单元格 `cell.text == "12.5m"`，不传 `strip_name` 保持旧行为）。
- **测试结果**：通过；`test_audit_fixes_20260927.py`（附录整块不丢失等 T1 断言）仍全绿。

### BUG-R179-04（P2）`declared_failed`（模型声明无事实段）对用户不可见

- **改了什么**：前端 `FactsSegmentFailuresAlert.tsx` 支持 `declared_failed` / `declared_failed_details`（L12-55，`info` 级提示 + 「下次增量提取会自动重试」）；`FactsTab.tsx` 渲染条件从仅 `failed>0` 扩为 `failed>0 || declared_failed>0`；`workbenchTypes.ts` 补齐字段。
- **为什么**：模型声明无事实的段既不计入 `ok` 也不计入 `failed`，旧告警只在 `failed>0` 时出现 → 用户只看到「ok 数变少」却没有任何原因提示（R175 缺口 4 未闭环）。
- **如何验证**：`factsTab.test.tsx` 新增 2 例（仅声明无事实 → info 文案且不误报失败；失败与声明并存 → 仍 warning 且展示声明明细）。
- **测试结果**：55 项通过；`tsc --noEmit` 0 error；定向 eslint 0 error（16 条 warning 为测试文件既有 `any`，本轮未新增）。
