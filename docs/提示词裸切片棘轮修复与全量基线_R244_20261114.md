## 2. 真实缺陷修复（4 条）

### 2.1 提示词契约 `{null}` 占位符误判（R242 回归）

`charts.py` 矩阵组织图自检行含 `` `{null} ∪ level2.id 集合` ``，`extract_user_variables`
把 `{null}` 误判为占位符变量 `null`，触发 `check_prompt_variables()` 违约。已改写为
`` `null`（直连总线）或已存在的 `level2` 节点 `id` ``（集合语义用「A 或 B」，不用
`` `{A}∪{B}` ``，避免花括号被当占位符——R242 教训④同族）。

`_registry.py` 为三个图表生成提示词补契约登记：

```python
PROMPT_VARIABLE_CONTRACTS["chart_gen_gantt_spec"]        = ["scheme_type"]
PROMPT_VARIABLE_CONTRACTS["chart_gen_org_matrix_spec"]   = ["scheme_type"]
PROMPT_VARIABLE_CONTRACTS["chart_gen_flow_complex_spec"] = ["scheme_type"]
```

验证：`check_prompt_variables() == []`，三提示词 `vars == requires == ["scheme_type"]`。

### 2.2 静默宽异常裸 `except`（`custom.py:95`）

`CustomAdapter.list_models` 的 `except Exception: pass` 无 `# noqa: BLE001` 标注，
`test_silent_broad_except_guard` 定罪。守卫 `_header_text` **只读 `except` 行本身**
（`end = max(handler.lineno, first_body_line - 1)`），noqa 注释必须写在 `except Exception:`
行而非 `pass` 行。已改为：

```python
except Exception:  # noqa: BLE001 - 网络/模型列表失败被有意吞掉，回退默认模型
    pass
```

### 2.3 提示词裸切片棘轮计数口径（非模型可见 60→61）

`test_prompt_bare_slice_scan_ratchet` 计数法 `len(zero_ledger) - len(model_facing)`
在**同一 `(path, code)` 出现多处**时失真。本轮新增 `routers/sections.py`
`run_omp_workflow` 的 `brief[:8000]` 安全上限切片（与已登记模型可见的
`generate_outline_via_omp` 同模式；因作用域名 `run_omp_workflow` 不含模型可见词
「omp 未入词表」而被启发式判非模型可见）。经逐条核对为**有界、带注释、发往模型可见
的安全截断**（同记账后提示词预算），按棘轮机制登记：`NON_MODEL_FACING_BASELINE` 60→61，
写明理由。修复后两测试全绿。
