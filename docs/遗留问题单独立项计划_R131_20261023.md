- 现有覆盖：`DLV-12` 规则 + 图号预检（仅报告，不修复）。

### 1.2 代码锚点（探查已确认）

|---|---|

| 既有护栏 | `test_audit_fixes_20260927.py`（T3 无 L1 时命名空间塌缩）、编号同步既有测试 |

### 1.3 阶段任务（遵循：计划 → 探查 → 基线 → 修复 → 回归）
1. **探查**：复现 78 次跨章借图的确切触发链（图表载荷 `section_id` 与
   `_figure_chapter_num` 归属章不一致的成因分支：目录重排后 / 章节移动后 /
   图表复用）；梳理 51 次编号一致性的具体形态（目录号 vs 正文号 vs 图号三者谁偏）。
2. **基线**：跑 `test_audit_fixes` + 编号/目录相关测试套，记录当前命中数
   与既有告警口径（只统计，不改行为）。
3. **修复方向**（候选，探查后定案）：
   - 图表归属以 `sort_order` 章节树为唯一事实源，渲染期按**当前树**重算归属；
   - 目录重排/章节移动后触发图号失效重算（复用既有 checkpoint 钩子）；
   - DLV-12 从「事后报告」升级为「导出预检拦截项」前，先验证不误伤。
4. **验证**：新增跨章借图回归护栏（正向 + 反例），全量回归零失败。

### 1.4 验收标准
- 构造「章节移动后图表归属漂移」的用例，修复后图号归属正确且不重号；
- 跨章借图/编号一致性告警在标准场景归零（日志口径可复算）；
- 既有 T3、编号同步、契约测试全部不回归。

### 1.5 风险与约束
- **禁止**改动 `sort_order` 语义（目录写、正文只读是 R130 已定契约）；
- 预检升级为拦截属**行为变更**，必须走配置开关且**默认保持现状**（纯加法）。

## 二、R132-B 提示词占位符未解析专项（P0）

### 2.1 背景与量化依据
- R130 日志最高频：`1134 + 260` 次占位符未解析；
- 与格式契约**无耦合**（契约不检查占位符），故 R130 刻意未纳入，避免扩界。

### 2.2 代码锚点（探查已确认）
| 用途 | 路径 |
|---|---|
| 占位符注册/解析主链 | `backend/app/services/ai/prompts/_registry.py` |
| 相关测试 | `backend/tests/test_scheme_repositioning_20261001.py` |
| 消费侧 | `sse_handlers` 各 AI 调用点（提示词渲染入口） |

### 2.3 阶段任务
1. **探查**：从日志反解出未解析占位符的**具体 token 高频 TOP 20**，按成因分桶：
   ① 模板声明了但填充函数漏传；② 填充条件分支未覆盖；③ 死模板残留 token；
   ④ 运行时才产生的动态占位（合法，需白名单豁免）。
2. **基线**：对 `_registry` 跑「全模板 × 全占位符」静态扫描测试，产出
   当前未解析清单（作为基线快照，后续轮次对比）。
3. **修复**：按桶逐一处理——漏传的补参、死 token 清理、合法动态占位登记白名单；
   扫描测试从「记录」升级为「断言不新增」（防回潮）。
4. **回归**：`test_scheme_repositioning` 及提示词相关套件全绿 + 全量回归。

### 2.4 验收标准
- 静态扫描：未解析占位符清单较基线下降且**零新增**；
- 运行日志同口径统计显著下降（用同一过滤条件复算）；
- 不改动提示词语义（只修解析链，不改文案内容——避免影响既有输出评审）。

### 2.5 风险与约束
- 提示词文案变更会连带影响所有 AI 输出，**本项只修解析/填充链路，不动文案**；
- 白名单豁免必须走集中登记处，禁止散落 `if token == ...` 硬编码（反分叉）。

### 4.5 风险与约束

- 改写属正文变更，必须进 `auto_fix_*` 开关族、默认关闭、可回滚（走既有

### 回归执行纪律（本轮实测教训）

- 后台回归输出**禁止经管道截断**（`Select-Object -Last N` 会吞掉失败明细，且
  `| Out-File` 曾导致中途异常退出）——应用进程级文件重定向落盘；
- 全量回归期间禁止任何 `.py` 写入（并行五段式编辑在窗口内造成 1 次假失败、
  1 次进程 86% 处中断作废重跑）；
- 子代理整文件改写后必须核对 EOL（本仓工作树约定纯 CRLF，字节体检有护栏）。
