   若未来 AI 大量产出，建议模块级 browser 复用或 batch_export 思路的预渲染段一次 gather

   定点重生成），可消费 chart_gen_*_spec + collect_json_response——涉及 SSE 链改动，独立立项。

## 六、教训归档

1. **「增强落地」必须紧跟「消费点普查」**——R237 四组件全部零消费躺一天无任何测试能发现
   「没人用它」；**可达性要单独造护栏**（消费点 grep 是收口轮的第一步）。
2. **死路契约的识别信号**：提示词要求 AI 输出「主链不存在的包裹形态」时，产出必然进不了
   任何消费侧——**提示词的输出契约必须以「主链消费判据」反推**（本轮 AI_Chart_Start 是
   已删除管线的历史标记，中文类型名连兼容判据都不认）。
3. **bytes 级替换脚本严禁 `text.replace('\n', CRLF)` 全文形态**——对已含 CRLF 的文本产生
   `\r\r\n`（519 处双 CR，R191 教训⑤的 CR 双写变体）；行尾对齐只应处理**新增片段**。
4. **`{null}` 花括号会被提示词契约检查误判为占位符变量**（contract_var_added）——
   提示词内表述集合语义用「A 或 B」而非 `{A}∪{B}`。
5. **to_png vs _render_html**：封装方法落盘、底层方法出 bytes——内存消费场景取底层
   （零临时文件）。
6. **多行变异锚在 CRLF 文件必失配**（R233 教训第 3 次复现）——A/B 锚一律单行。
