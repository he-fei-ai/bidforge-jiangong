```

        ├─ invalidate_export_cache（导出缓存失效）

   → 目录生成 / 正文生成：facts_builder.build_facts_text 注入

```

## 八、新增配置项说明与向后兼容性

**本轮零新增配置项、零环境变量、零迁移、零 DDL。** 所有改动均为加法式或收口式：

- `project_facts_inproc_guard` 为内部上下文管理器，不读任何配置；等待超时（沿用既有 `LOCK_WAIT_SECONDS`）时 yield `False` 并降级继续，不抛异常、不阻断业务。
- `safeFactText` 对合法字符串**逐字节不变**；`factConfidencePercent` 对合法 0~1 数值输出与原 `(v*100).toFixed(0)` 一致；`factConfidenceColor` 四档阈值逐值不变，仅 `null` 新增灰色。
- `group_count` 为 `format_for_frontend` 返回值新增键，旧客户端忽略该键行为不变。
- 分类别名归一**不扩** `_ALLOWED_FACT_CATEGORIES`，未知值仍回落 `other`。
- `crossConflicts` 回读仅在本地冲突数组为空时补齐，SSE 实时态优先；请求失败/被 abort 完全自吞，绝不让事实列表加载失败。
- `audit_out` 为既有出参，不改变 `build_facts_text` 的渲染文本（护栏断言 `rendered_text` 与旧实现逐字节一致）。
- 前端新增 `pagination` 控件位置从「仅全量分支」变为「两分支之外」，总数不足一页时仍按 `buildFactsPagination` 返回不渲染（零行为变更护栏已测）。

**运维**：需重启后端（`sse_handlers` / `facts_extractor` / `global_facts` / `global_facts_docs` / `facts_write_guard` / `prompts.analysis` 常驻）；**前端需重建**（`FactsTab` / `FactsGroupList` / `factsShared` / `SchemeWorkbenchPage` / `api/index.ts` / `workbenchTypes`）；无需清库、无需迁移。

**效果复算锚（下批日志）**：分类视图出现分页控件且可翻页；`confidence` 缺失显示「置信度未知」而非 `NaN%`；长 `source_ref` 显示前 30 字；切方案后诊断面板不再永久转圈；删除/重解析文档与 AI 提取并发时新事实仍正确标 stale；目录生成日志出现「目录生成事实预算丢弃 N 条」；`all_skipped` 终态后断线重挂能拿回 `segment_stats / cross_conflicts`；刷新页面后已落库跨段矛盾横幅仍可见。
