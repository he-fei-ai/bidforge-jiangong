# 字数收尾透明警告 + 前端并列口径收口 · R71（2026-10-12）

> 承接 R70《正文链体检与易标字数标准对账》。用户决定：**不切换 `text_word_count` 权威判定口径**
> （那会推翻 R70 刚锁定的唯一口径反向护栏 + 触发落库迁移），只做**加法式**收口：
> F2 前端 5 处并列口径统一到「后端值优先、缺失显示 —」+ R12 收尾透明警告（advisory，不阻断、不进判定/落库）。
> 零新增依赖、零数据迁移、零判定行为变更、前端零新增配置项。

## 1. 范围与决策

| 项 | 决策 | 依据 |
|---|---|---|
| 切换 `text_word_count` 为可读口径 | **不做**（递延带证据评审） | R70 §11.1：33 章语料字符口径 mean 136.9% vs 可读 106.5%，换算系数 1.285 总量级稳但**逐章非常数**（表格密集≈1.30 / 散文≈1.20）；切口径 = 推翻 R70 唯一口径护栏 + 全库 word_count 回填迁移 |
| F2 前端 5 处并列口径 | 后端值优先、缺失显示 — / 改标「字符」 | R70 §7.4：前端 `content.length` 兜底是**第三种口径**（原始字符含围栏），与后端权威落库值并存即自相矛盾 |
| R12 失败不硬裁 → 人工核对 | 加法式 advisory 收尾警告 | 易标报告 §7.5；仿 R65 `report["structure"]` 接线模式，只 info-log，不改 error/warning 计数、不阻断 |

## 2. 后端改动

### 2.1 `app/services/content_utils.py` · 新增 `word_closeout_notice`（~407 行）

纯函数，签名 `word_closeout_notice(word_count, word_budget, *, tolerance=0.1) -> dict`：

- **复用唯一判定**：内部走 `word_status_for`（同一 0.8×/1.3× 阈值，`WORD_UNDER_RATIO`/`WORD_OVER_RATIO`），不自造第二把尺子；
- 返回 `{"advisory", "kind", "message", "word_status", "ratio", "within_band", "severity": "advisory"}`（键集被护栏锁死）；
- under → 「续写未能补齐或已停止，系统不强行灌写——请人工核对是否需要补充」；over → 「系统按『宁可超字数，不可损坏正文』未强行裁剪——请人工核对是否需要精简」；normal → `advisory=False`、`message=""` 静默；
- 脏值不抛（`None`/`"abc"` → 0；预算 0/None → `DEFAULT_WORD_BUDGET` 兜底）；
- **函数体绝不引用** `readable_word_count` / `has_cjk`（AST 护栏锁死，否则是 R70 反向锁之外的第二把尺子）。

### 2.2 `app/routers/sse_handlers.py` · R12 接线（structure advisory 块之后）

```python
_word_rep = word_closeout_notice(wc, word_budget)
report = dict(report or {})
report["word"] = _word_rep
report_json = json.dumps(report, ensure_ascii=False)
if _word_rep.get("advisory"):
    logger.info("章节 %s 字数收尾提示（仅建议，不阻断）：%s", ...)
```

整体包 `try/except`（失败只 WARNING、不影响落库）。`wc` 是本作用域既有 `text_word_count` 结果——判定与落库路径一字未动。

### 2.3 `app/routers/charts.py` · fix_mermaid 回带权威 `word_count`

- 初始化 `section_word_count = None`；正文重写成功时 `section_word_count = wc`（`wc = text_word_count(patched)`）；回滚 except 分支重置 `None`；响应 dict 新增 `"word_count": section_word_count`。
- additive 键：既有测试只断言具体键（`validated/code/written_back/content_updated`），非精确键集，零破坏。
- **未重写正文绝不谎报字数**（回滚 → None，前端据此不动本地值）。

## 7. 遗留 / 递延（记录以免重复排查）

1. **口径切换本体**（字符→可读）：需「预算重标定 + 33 章语料系数逐章分布 + 落库回填迁移」三件套同轮做，且要与 R70 反向护栏的解除方案一起评审——本轮按用户决定不动。
2. **树节点显示与状态同屏分叉**（R70 round5 已量化）：改后前端一律以后端 `word_count` 为准，真实库「权威 0 但原始字符>0」= 0 处，暂无活体分叉；若未来出现「正文只有围栏图表」章节，显示 0 而原始字符>0 是**正确行为**（权威口径就是剔围栏 0），不是缺陷。
3. `word_closeout_notice` 的 `tolerance=0.1` 只影响 `within_band/ratio` 展示字段，不影响 `advisory` 触发（触发只认 `word_status_for`）。
