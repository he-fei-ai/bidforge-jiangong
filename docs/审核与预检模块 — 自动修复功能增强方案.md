# 审核与预检模块 — 自动修复功能增强方案

> **模块定位**：七步流水线第 6 步「质量门禁」  
> **增强目标**：从"发现问题"升级为"发现问题 + 自动定位 + 自动修复 + 自动校验 + 可回滚"  
> **增强日期**：2026-10-01  
> **关联功能**：审核工作流、程序化预检、AI 语义判定、一致性修复、就绪度聚合

---

## 一、功能定位

### 1.1 一句话定义

**自动修复（Auto-Fix Agent）**：在审核与预检模块发现问题后，由 AI Agent 自动定位问题所在的章节、段落、句子，直接对正文进行改写修正，经校验通过后落库，并支持逐条确认、批量修复、一键回滚。

### 1.2 与现有能力的关系

| 能力        | 现有                   | 增强后                         |
| ----------- | ---------------------- | ------------------------------ |
| 程序化预检  | 发现问题、输出 finding | 发现问题 + 自动定位 + 自动修复 |
| AI 合规检查 | 判定合规、输出建议     | 判定合规 + 自动改写            |
| 一致性审计  | 检测冲突               | 检测冲突 + 仲裁 + 修复（已有） |
| 审核工作流  | 人工审核状态机         | 人工审核 + AI 预修复           |
| 就绪度聚合  | 评分 + 放行结论        | 评分 + 一键修复全部阻断项      |

### 1.3 核心价值

1. **从"报告"到"修复"**：用户不再需要人工逐条修改，AI 直接改写。
2. **定位到句**：精确定位到段落、句子，而非仅章节。
3. **可回滚**：每次修复生成快照，支持一键回滚。
4. **可逐条确认**：用户可逐条接受/拒绝，避免误改。
5. **闭环联动**：修复后自动触发审核退回、一致性缓存失效、预检结论过期。

## 四、核心模块设计

### 4.1 问题收集器（FindingCollector）

**职责**：从多个来源收集所有问题，统一为 `LocatedFinding` 格式。

```python
class FindingCollector:
    """问题收集器"""
    
    async def collect(self, scheme_id: str) -> list[LocatedFinding]:
        findings = []
        
        # 1. 程序化预检
        findings.extend(await self._collect_preflight(scheme_id))
        
        # 2. AI 合规检查
        findings.extend(await self._collect_compliance(scheme_id))
        
        # 3. 一致性审计
        findings.extend(await self._collect_consistency(scheme_id))
        
        # 4. 导出预检
        findings.extend(await self._collect_export_issues(scheme_id))
        
        # 5. 专家论证
        findings.extend(await self._collect_expert_review(scheme_id))
        
        # 去重（按 rule_id + section_id + 原文片段）
        findings = self._deduplicate(findings)
        
        # 按严重程度排序
        findings = self._sort_by_severity(findings)
        
        return findings
    
    def _deduplicate(self, findings: list) -> list:
        """按 rule_id + section_id + 原文片段去重"""
        seen = set()
        unique = []
        for f in findings:
            key = (
                f.rule_id,
                f.section_id,
                f.location.original_text[:50] if f.location else ""
            )
            if key not in seen:
                seen.add(key)
                unique.append(f)
        return unique
    
    def _sort_by_severity(self, findings: list) -> list:
        """按严重程度排序：block > high > medium > low"""
        order = {"block": 0, "high": 1, "medium": 2, "low": 3}
        return sorted(findings, key=lambda f: order.get(f.severity, 99))
```

### 4.2 定位器（Locator）

**职责**：将 finding 定位到具体的章节、段落、句子。

```python
class Locator:
    """问题定位器"""
    
    async def locate(self, finding: Finding, scheme: Scheme) -> LocatedFinding:
        # 1. 定位章节
        section = self._locate_section(finding, scheme)
        if not section:
            return self._mark_manual_required(finding, "无法定位章节")
        
        # 2. 定位段落
        paragraph_idx = self._locate_paragraph(finding, section)
        
        # 3. 定位句子
        sentence_idx, start_offset, end_offset = self._locate_sentence(
            finding, section, paragraph_idx
        )
        
        # 4. 提取原文
        original_text = self._extract_text(
            section, paragraph_idx, start_offset, end_offset
        )
        
        # 5. 判断是否可自动修复
        auto_fixable = self._is_auto_fixable(finding, original_text)
        
        return LocatedFinding(
            finding_id=finding.id,
            rule_id=finding.rule_id,
            severity=finding.severity,
            dimension=finding.dimension,
            title=finding.title,
            message=finding.message,
            section_id=section.id,
            section_title=section.title,
            location=Location(
                paragraph_idx=paragraph_idx,
                sentence_idx=sentence_idx,
                start_offset=start_offset,
                end_offset=end_offset,
                original_text=original_text
            ),
            repair_strategy=self._determine_strategy(finding),
            repair_hint=finding.suggestion,
            auto_fixable=auto_fixable,
            locate_confidence=self._compute_confidence(finding, original_text)
        )
    
    def _locate_section(self, finding: Finding, scheme: Scheme) -> Section | None:
        """定位章节"""
        # 1. 如果 finding 已有 section_id，直接使用
        if finding.section_id:
            return scheme.get_section(finding.section_id)
        
        # 2. 按标题关键词匹配
        if finding.title:
            for section in scheme.sections:
                if finding.title in section.title or section.title in finding.title:
                    return section
        
        # 3. 按内容关键词匹配
        if finding.keywords:
            best_match = None
            best_score = 0
            for section in scheme.sections:
                score = self._keyword_match_score(section.content, finding.keywords)
                if score > best_score:
                    best_score = score
                    best_match = section
            if best_score > 0.5:
                return best_match
        
        return None
    
    def _locate_paragraph(self, finding: Finding, section: Section) -> int:
        """定位段落"""
        paragraphs = section.content.split("\n\n")
        
        # 1. 如果 finding 有原文片段，查找匹配段落
        if finding.original_text:
            for i, p in enumerate(paragraphs):
                if finding.original_text in p:
                    return i
        
        # 2. 按关键词匹配
        if finding.keywords:
            best_idx = 0
            best_score = 0
            for i, p in enumerate(paragraphs):
                score = self._keyword_match_score(p, finding.keywords)
                if score > best_score:
                    best_score = score
                    best_idx = i
            return best_idx
        
        # 3. 默认返回最后一段（通常补充内容加在末尾）
        return len(paragraphs) - 1
    
    def _locate_sentence(
        self,
        finding: Finding,
        section: Section,
        paragraph_idx: int
    ) -> tuple[int, int, int]:
        """定位句子（返回：句子索引、起始偏移、结束偏移）"""
        paragraphs = section.content.split("\n\n")
        if paragraph_idx >= len(paragraphs):
            return 0, 0, 0
        
        paragraph = paragraphs[paragraph_idx]
        sentences = self._split_sentences(paragraph)
        
        # 1. 如果 finding 有原文片段，查找匹配句子
        if finding.original_text:
            for i, s in enumerate(sentences):
                if finding.original_text in s:
                    offset = paragraph.find(s)
                    return i, offset, offset + len(s)
        
        # 2. 按关键词匹配
        if finding.keywords:
            best_idx = 0
            best_score = 0
            for i, s in enumerate(sentences):
                score = self._keyword_match_score(s, finding.keywords)
                if score > best_score:
                    best_score = score
                    best_idx = i
            s = sentences[best_idx]
            offset = paragraph.find(s)
            return best_idx, offset, offset + len(s)
        
        # 3. 默认返回最后一句
        if sentences:
            s = sentences[-1]
            offset = paragraph.find(s)
            return len(sentences) - 1, offset, offset + len(s)
        
        return 0, 0, 0
    
    def _split_sentences(self, text: str) -> list[str]:
        """分句"""
        import re
        # 按中文标点分句
        sentences = re.split(r'(?<=[。！？；])', text)
        return [s for s in sentences if s.strip()]
    
    def _determine_strategy(self, finding: Finding) -> str:
        """确定修复策略"""
        rule_id = finding.rule_id
        
        # 按规则类型匹配策略
        if rule_id.startswith("CMP"):  # 完整性
            return "append"  # 补充缺失内容
        elif rule_id.startswith("SAF"):  # 安全
            return "append"  # 补充安全措施
        elif rule_id.startswith("STD"):  # 规范
            return "replace"  # 替换为规范表述
        elif rule_id.startswith("CON"):  # 一致性
            return "replace"  # 替换为一致表述
        elif rule_id.startswith("DLV"):  # 交付
            return "rewrite"  # 整段重写
        elif rule_id.startswith("TRC"):  # 追溯
            return "append"  # 补充追溯信息
        else:
            return "replace"  # 默认替换
    
    def _is_auto_fixable(self, finding: Finding, original_text: str) -> bool:
        """判断是否可自动修复"""
        # 1. 规则是否支持自动修复
        if not self._rule_supports_autofix(finding.rule_id):
            return False
        
        # 2. 是否有足够的原文
        if not original_text or len(original_text) < 10:
            return False
        
        # 3. 是否涉及结构性变更（如调整章节顺序）
        if finding.rule_id in self.STRUCTURAL_RULES:
            return False
        
        return True
    
    STRUCTURAL_RULES = {
        "CMP-01",  # 章节缺失
        "CMP-02",  # 章节顺序错误
        "DLV-01",  # 封面缺失
        "DLV-02",  # 目录缺失
    }
    
    def _compute_confidence(self, finding: Finding, original_text: str) -> float:
        """计算定位置信度"""
        confidence = 0.5
        
        # 有 section_id
        if finding.section_id:
            confidence += 0.2
        
        # 有原文片段
        if finding.original_text:
            confidence += 0.2
        
        # 关键词匹配度高
        if finding.keywords and original_text:
            score = self._keyword_match_score(original_text, finding.keywords)
            confidence += score * 0.1
        
        return min(confidence, 1.0)
```

    async def plan(
        self,
        findings: list[LocatedFinding],
        scheme: Scheme,
        global_facts: list

                items.append(self._mark_manual(finding))
                continue
            
            template = self.STRATEGY_TEMPLATES.get(finding.repair_strategy)

                original_text=finding.location.original_text,
                repair_hint=finding.repair_hint,

            ))
        
        return RepairPlan(
            plan_id=self._generate_id(),
            scheme_id=scheme.id,
            total_findings=len(findings),
            auto_fixable=sum(1 for i in items if i.status == "pending"),

### 4.4 AI 修复器（RepairAgent）

**职责**：调用 AI 执行修复。

```python
class RepairAgent:
    """AI 修复器"""
    
    def __init__(self, provider):
        self.provider = provider
    
    async def apply(
        self,
        plan: RepairPlan,
        scheme: Scheme
    ) -> RepairResult:
        results = []
        
        # 按章节分组，减少重复加载
        by_section = self._group_by_section(plan.items)
        
        for section_id, items in by_section.items():
            section = scheme.get_section(section_id)
            if not section:
                continue
            
            # 逐条修复
            for item in items:
                if item.status != "pending":
                    continue
                
                try:
                    result = await self._apply_one(item, section)
                    results.append(result)
                    
                    # 更新 section 内容（临时）
                    section.content = self._apply_to_content(
                        section.content, item, result.after
                    )
                except Exception as e:
                    results.append(RepairResultItem(
                        finding_id=item.finding_id,
                        section_id=section_id,
                        status="failed",
                        error=str(e)
                    ))
        
        return RepairResult(
            repair_id=self._generate_id(),
            plan_id=plan.plan_id,
            scheme_id=scheme.id,
            total=len(results),
            repaired=sum(1 for r in results if r.status == "repaired"),
            skipped=sum(1 for r in results if r.status == "skipped"),
            failed=sum(1 for r in results if r.status == "failed"),
            items=results
        )
    
    async def _apply_one(
        self,
        item: RepairPlanItem,
        section: Section
    ) -> RepairResultItem:
        # 调用 AI
        messages = [
            {"role": "system", "content": "你是专项方案修复助手。"},
            {"role": "user", "content": item.repair_prompt}
        ]
        
        response = await self.provider.chat(messages)
        new_text = response.strip()
        
        # 处理特殊情况
        if item.strategy == "delete" and new_text == "KEEP":
            return RepairResultItem(
                finding_id=item.finding_id,
                section_id=section.id,
                status="skipped",
                reason="AI 判定不应删除"
            )
        
        return RepairResultItem(
            finding_id=item.finding_id,
            section_id=section.id,
            before=item.original_text,
            after=new_text,
            status="repaired"
        )
    
    def _apply_to_content(
        self,
        content: str,
        item: RepairPlanItem,
        new_text: str
    ) -> str:
        """将修复结果应用到正文"""
        # 定位并替换
        start = item.target.start_offset
        end = item.target.end_offset
        
        # 注意：这里需要根据段落索引重新计算全局偏移
        # 简化处理：直接字符串替换
        if item.original_text in content:
            return content.replace(item.original_text, new_text, 1)
        
        return content
```

### 4.5 校验器（Validator）

**职责**：校验修复结果是否正确。

```python
class RepairValidator:
    """修复校验器"""
    
    async def validate(
        self,
        result: RepairResultItem,
        finding: LocatedFinding,
        section: Section,
        global_facts: list
    ) -> ValidationResult:
        checks = []
        
        # 1. 规则校验：问题是否已消除
        rule_resolved = await self._check_rule_resolved(
            finding, result.after
        )
        checks.append(("rule_resolved", rule_resolved))
        
        # 2. 一致性校验：是否与全局事实一致
        consistency_ok = self._check_consistency(
            result.after, global_facts
        )
        checks.append(("consistency_ok", consistency_ok))
        
        # 3. 结构校验：段落、列表、表格、编号是否保留
        structure_ok = self._check_structure(
            result.before, result.after
        )
        checks.append(("structure_ok", structure_ok))
        
        # 4. 字数校验：变化是否在合理范围
        word_count_ok = self._check_word_count(
            result.before, result.after
        )
        checks.append(("word_count_ok", word_count_ok))
        
        # 5. 新问题校验：是否引入新问题
        new_issues = await self._check_new_issues(
            result.after, section, global_facts
        )
        checks.append(("no_new_issues", len(new_issues) == 0))
        
        passed = all(ok for _, ok in checks)
        
        return ValidationResult(
            passed=passed,
            checks=dict(checks),
            new_issues=new_issues,
            word_count_delta=len(result.after) - len(result.before)
        )
    
    async def _check_rule_resolved(
        self,
        finding: LocatedFinding,
        new_text: str
    ) -> bool:
        """检查规则是否已解决"""
        # 按 rule_id 调用对应检查器
        from app.services.preflight_engine import RULE_CHECKERS
        
        checker = RULE_CHECKERS.get(finding.rule_id)
        if not checker:
            return True  # 无检查器则默认通过
        
        return await checker(new_text)
    
    def _check_consistency(
        self,
        text: str,
        global_facts: list
    ) -> bool:
        """检查与全局事实的一致性"""
        for fact in global_facts:
            if fact["type"] == "numeric":
                # 检查数值是否矛盾
                if self._has_conflicting_value(text, fact):
                    return False
        return True
    
    def _check_structure(
        self,
        before: str,
        after: str
    ) -> bool:
        """检查结构是否保留"""
        import re
        
        # 检查列表符号
        before_lists = len(re.findall(r'^[\-\*]\s', before, re.MULTILINE))
        after_lists = len(re.findall(r'^[\-\*]\s', after, re.MULTILINE))
        if before_lists > 0 and after_lists == 0:
            return False
        
        # 检查编号
        before_nums = len(re.findall(r'^\d+[\.、]', before, re.MULTILINE))
        after_nums = len(re.findall(r'^\d+[\.、]', after, re.MULTILINE))
        if before_nums > 0 and after_nums == 0:
            return False
        
        # 检查图表引用
        before_charts = len(re.findall(r'<<CHART:', before))
        after_charts = len(re.findall(r'<<CHART:', after))
        if before_charts != after_charts:
            return False
        
        return True
    
    def _check_word_count(
        self,
        before: str,
        after: str,
        max_delta_ratio: float = 2.0
    ) -> bool:
        """检查字数变化是否合理"""
        before_len = len(before)
        after_len = len(after)
        
        if before_len == 0:
            return True
        
        ratio = after_len / before_len
        return 0.5 <= ratio <= max_delta_ratio
```

### 4.6 落库器（Persister）

**职责**：将修复结果写入数据库，并触发联动。

```python
class RepairPersister:
    """修复落库器"""
    
    async def persist(
        self,
        result: RepairResult,
        scheme: Scheme,
        findings: list[LocatedFinding]
    ) -> RepairResult:
        # 1. 创建快照
        snapshot = await self._create_snapshot(scheme, result)
        
        # 2. 写入章节内容
        for item in result.items:
            if item.status != "repaired":
                continue
            
            section = scheme.get_section(item.section_id)
            if not section:
                continue
            
            section.content = self._apply_to_content(
                section.content, item
            )
            await self._save_section(section)
        
        # 3. 触发审核退回
        for item in result.items:
            if item.status == "repaired":
                await reset_review_on_content_change(
                    scheme.id, item.section_id
                )
        
        # 4. 触发一致性缓存失效
        await invalidate_consistency_scan_cache(
            scheme.id, [i.section_id for i in result.items if i.status == "repaired"]
        )
        
        # 5. 标记预检结论过期
        await self._invalidate_preflight_runs(scheme.id)
        
        # 6. 保存修复结果
        await self._save_repair_result(result, snapshot.id)
        
        return result
```
