```
解析提取(import) ──► 正文/目录落库 ──► 编号规范化 ──► 导出 DOCX

  但一旦错位就是**静默的原文销毁**（§六 FIX-1）。

## 五、发现的缺陷（含根因推演）

### BUG-1（P0）· 围栏递归导致 `src_line` 相对化 ⇒ **原文整行被覆盖销毁** + 编号虚跳

**症状**：`-k outline` 全量基线稳定 1 红：

```
FAILED tests/test_outline_generation_gaps_20261008.py::
  TestEncodingAndLargePayload::test_heading_inside_code_fence_with_unicode_is_untouched
```

**取证**（`artifacts/r118/repro_src_line.py`，UTF-8 输出）：

```
INPUT : '```markdown\n＃＃ 围栏内全角井号\n## 围栏内标题\n```\n\n## 真标题\n'
OUTPUT: '```markdown\n## 2.1 围栏内标题\n## 围栏内标题\n```\n\n## 2.2 真标题\n'   ← 修复前
CHANGES: line=2 old='围栏内标题' new='2.1 围栏内标题' ; line=6 old='真标题' new='2.2 真标题'
```

**根因链**：

1. R117 在 `content_blocks.py:799` 让 ```` ```markdown ```` 围栏递归解析，
   但递归传入的是**围栏内部文本**；
2. 子块上的 `src_line` 因此是**围栏内相对下标**（实测 = 1）；
3. `numbering.py:558` 把它直接当 `content.split("\n")` 的索引使用；
4. 外层 `lines[1]` 恰好是全角井号行 ⇒ **被整行覆盖，`＃＃ 围栏内全角井号` 永久丢失**；
5. 同时围栏内标题吃掉 2.1，真标题顺延成 2.2 ⇒ **编号虚跳**；
   而导出侧 `_collapse_repeated_blocks`（`export.py:2273`）还会对「围栏内一份 +
   围栏外重述一份」去重渲染 ⇒ 落库阶段白耗的序号在成稿里表现为编号空洞。

**为什么第 4 步是最严重的**：这不是「编号不好看」，是**交付内容被静默删除**，
且不会产生任何日志或异常。

---

### BUG-2（P2）· 子进程输出按 locale 严格解码 ⇒ 后台读线程 UnicodeDecodeError

**症状**（后端全量回归日志 `logs/full_r118_after_fix1.txt` 原文）：

```
UnicodeDecodeError: 'gbk' codec can't decode byte 0xa1 in position 23: illegal multibyte sequence
  File "C:\Program Files\Python314\Lib\subprocess.py", line 1614, in _readerthread
```

**根因**：`app/utils/process_cleanup.py:215` 的 `tasklist` 探活用了 `text=True`
但**未指定 `errors`**，Python 按 locale（本机 cp936/GBK）**严格**解码。
同族故障在 `ai/mermaid_service.py:353-372` 已被修（其注释明确记载「会在 subprocess
的 reader 线程内抛 UnicodeDecodeError…白白等待到 timeout」），但 `_pid_alive` 是漏网的
sibling。`except Exception` 只能拿到空 stdout ⇒ 探测结果失真（保守判活）。

---

### BUG-3（P3）· 墙钟断言抖动

`tests/test_perf_content_pipeline.py:276` 的 `assert elapsed < 0.8` 在全量（9366 项 /
9 分 24 秒）跑到 63% 处时抖动变红；单独跑该文件 31 passed / 5.22s。属测试基础设施缺陷。

| 关键函数 | 改动 |
|---|---|
| `renumber_section_body_subheadings`（L529-554） | 新增 `_renumberable = [b for b in blocks if b.get("type")=="heading" and not b.get("_from_fence")]`；**第一遍（算号）与第二遍（重写源行）统一遍历它**，并写明三条理由（占号 / 去重后空洞 / 契约） |

  `test_outline_generation_gaps_20261008.py::D-8g` 的既有契约并造成编号虚跳。

**不属于本修复的边界**：`export.py` 的渲染侧继续按 R117 语义渲染围栏内内容（有意），
本轮不改。
