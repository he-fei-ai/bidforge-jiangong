## 2. 缺陷定稿

### F1 · P1 · DLV-14 图号/表号漂移检测不可达

**根因**：`collect_export_issues` 的 `_detect_stale_cross_references` 只拿「本章节引用过的编号集合」，跨章引用（图 3-1 在第 5 章正文、编号在第 3 章生成）⇒ **漏报 stale**。

**修复**：新增 `collect_figure_table_number_superset(sections)` 供给「全树最宽松上界」编号集合（自身+全部子孙，零假阳性，malformed tree 降级空集），接线为 `real_nums=` 关键字参数（受 `settings.crossref_stale_detect_enabled` 门控，默认 True）。

**实证**：探针 `artifacts/exp94/probe_e2e.py` 实测 0→4 stale issues、0 false positives。

### F2 · P2 · `_record_placeholder_baseline` R13 裸 `db.execute`

**根因**：INSERT + prune(DELETE) 两处裸 `await db.execute(...)` 绕过 `_db_exec` 单一出口（R13 `cur is None` → `AttributeError` 被外层 `except` 吞掉 → 中断项静默残留、prune 0 行不报）。

**修复**：全部收敛到 `_db_exec`（写路径 `require_rows=True` ⇒ 未生效即 503），prune 改为 `if inserted:` 门控。

### F3 · P2 · 围栏自动修复计数缺 X-Fix-Stats

**根因**：`auto_fix_unclosed_fences`（导出前置补齐未闭合围栏）的修复条数此前**只进 backend.log、不进 X-Fix-Stats 响应头**，用户无从得知「导出时自动修了几处围栏」。

**修复**：`_FIX_STATS_KEYS` 尾部追加 `"fences_fixed"`；`audit_content` 新增 `fences_fixed` 形参，>0 时产 `fence_auto_fixed` advisory；`_prepare_export` 统计累加 → `_build_docx_sync` 透传 → 线程局部 `_fix_stats` → X-Fix-Stats 三处出口（docx/pdf/plan JSON）。

### F4 · P3 · 全角 CHART_TYPE 标记泄漏 + charts.py 字面量漂移

**根因**：AI 偶发写 `【CHART_TYPE: gantt】`（全角方括号），旧正则只认半角 `[[CHART_TYPE:` ⇒ 标记原样进交付件。`charts.py::_is_placed` 内联 `f"[CHART_TYPE: {ct}]"` 字面量副本与登记侧判据分叉。

**修复**：`content_blocks.py` 新增 `_RE_CHART_TYPE_TAG`（半角+全角）+ `_RE_CHART_TYPE_TAG_LOOSE` + `chart_type_tags(text)` 单一出口；`charts.py::_is_placed` 改调单一出口；畸形标记行跳过不原样打印。

## 3. 增强项

### E1 · P2 · 缓存命中仍跑全量渲染

**根因**：`_prepare_export` 此前把取数+渲染混在一个函数体内——即使缓存命中也照跑 `_auto_generate_ai_image_blocks`/`_download_remote_image`/`get_or_render`（图表重渲/位图重下载/AI 编排重跑）。

**修复**：拆为取数段 `_prepare_export`（产 plan，零渲染调用）+ 渲染段 `_prepare_export_render`（填充 plan 的 render_stats）；`export_docx`/`export_pdf` 在缓存查询**之前**调取数段、缓存命中即跳渲染段；新增 `_build_docx_options` 抽取；新配置 `export_cache_fast_path: bool = True`（`EXPORT_CACHE_FAST_PATH` env，置 False 逐字回退旧行为）。

**实证**：探针实测缓存命中时 `get_or_render` 调用 2→0。

## 4. 健壮性

`_section_sort_key` 对 `level` 为非数字/None 时 `int()` 抛 `ValueError` → `collect_figure_table_number_superset` / `collect_export_issues` 整体 500。加 `try/except (TypeError, ValueError): level = 1`。
