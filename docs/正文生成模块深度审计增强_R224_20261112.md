## 九、教训归档

1. **「护栏先跑」救了 F8 两轮**：首版「判据走 normalize」是**空转修复**（探针实测 normalize 不闭合围栏，bare=norm=5）；第二版「前移 auto_fix」被 R179 吞正文观测护栏当场抓获（前移让 persist 无事可做、`fence_swallowed_prose` 静默消失）——**每次改判据/整形链，先跑底层行为探针，再跑全簇护栏**，两个方向各抓一次。
2. **isort 会重排 import 语句破坏初始化顺序**（R218 教训③新变体）：测试文件里 `import a.b` 与 `import a.c` 的顺序依赖会被 `ruff --fix` 按字母序打乱——顺序敏感的初始化用 `importlib.import_module` 固化。
3. **A/B 变异名不得包含原子串**：`_x` → `_x_AB` 的改名让 `"x" in src` 探针恒真（子串自咬，R166 家族第 4 次实证）——变异新名必须与原子串无包含关系。
4. **services → routers 的依赖方向是 AST 级硬契约**：连函数内懒导入都会被抓；跨层复用单一写入口的正确姿势是「services 回报清单 + 路由层执行」（R188 L10 resync_fn 同纪律）。
5. **拆分守卫的名单会随新符号增长**：在含拆分历史的模块新增与已拆出同名符号（本例熔断函数）会被 R172 守卫拦下——先 grep 拆分转发块，转发导入而非重定义。
6. **基线红先查落盘时间线**：本轮唯一基线红（对拍表）是并行会话在基线启动后 30 分钟才落盘的登记——`ls -l --time-style` 对比基线启动时间即可归因，不必先怀疑自己。
