## 六、本轮教训（归档）

1. **A/B mutation 必须语法安全**：去掉关键代码块若导致源码语法错误，`_syntax_ok` gate 会在 `return False` 时**不 restore**，留下 residue 在源文件中（本轮曾污染 provider_factory.py / image_engine.py，需手工 restore）。定稿版改为全部替换为不含关键字的注释，每条独立 try/finally restore + sha 自校，6/6 CAUGTS 且无 residue。
2. **静态文本锁要把关键字也从注释里剔除**：替换为注释时若注释仍含断言依赖的字符串，静态锁不会 fail（假护栏）。定稿版注释只写 `MUTATED_AB Mn`，不含原关键字。
3. **`ast.walk` 扫函数体时须剥 docstring**：函数首节点 docstring 也是 `ast.Constant` 字符串，会被误当判据字面量（本轮 `test_rate_limit_not_in_permanent_set` 首版即此坑，说明文字含 "HTTP 429" 导致假失败）。
