### 实现与设计意图不符处

1. **`/upload-outline/{id}/save-as-outline` 已成后端孤路由**：前端契约清理移除调用（api/index.ts:345），但后端保留 435 行高复杂度实现（三层标题匹配、正文保留、占位闸门、级联清理，upload_outline.py:389-824）且 27+30 例测试持续维护。真实链路经 outline_library.applyAndSave。属"设计意图（四类写入口全覆盖）与现实（该入口 UI 不可达）"的偏差（T1）。
2. **目录识别链的 parse_warnings 持久化到 `uploaded_outlines.parse_warnings`（:349）但该链路没有任何读取回放入口**（grep 全仓仅 upload_outline.py:839 的 db._migrate 声明），刷新后诊断不可回看——与资料链（列表接口回传）口径不一致（T4）。

## 六、确定 BUG 清单（3 项）

### BUG-1（P1·中）并发同名上传产生重复 project_documents 行

- **证据**：同名替换为「SELECT（:620-623）→ DELETE（:642-643）→ INSERT（:653-659）」非原子序列，且表上只有普通索引 `idx_project_documents_project`（schema_sql.py:173），**无 UNIQUE(project_id, file_name)**。连接为池化独立连接（db.py:1374-1379「连接池复用…写入由 WAL 在数据库层串行化」）——串行化仅保证写不损坏，不阻止「A、B 的 SELECT 都落在对方 commit 之前」的交错。
- **触发条件**：同项目下两个并发请求上传同名文件（双开标签页、双击重试、脚本直连）。
- **后果**：两行同名档案 + 两个磁盘文件并存；`load_parsed_docs`（:104-151，全量）把同一文档正文**重复**送进事实提取输入；后续同名上传虽会删光同名旧行（:632 `fetchall` 循环）形成部分自愈，但窗口内数据已重复且无任何告警。
- **建议修法**：增量迁移加 `CREATE UNIQUE INDEX ux_project_documents_pid_fname ON project_documents(project_id, file_name)`，INSERT 捕获 IntegrityError 转为替换语义；或 INSERT 前在事务内 `SELECT ... + 立即 INSERT` 并依赖唯一索引兜底。注意旧库需先去重再建索引。

### BUG-2（P2·低）UTF-16 文本文件不识别，GBK 静默乱码入库

- **证据**：`_decode_text_ex` 回退链只有 `utf-8-sig → gbk → gb18030 → utf-8(ignore)`（file_parser.py:594-614），无 UTF-16 BOM（`\xff\xfe` / `\xfe\xff`）分支。UTF-16LE 中文文件按 GBK 逐字节对解码**大概率成功**，落到「已按 gbk 解码（可能存在乱码）」告警分支。
- **触发条件**：Windows 记事本「Unicode」编码保存的 .txt/.csv（招投标场景真实存在）。
- **后果**：乱码正文进入 `parsed_markdown`/`raw_text`，事实提取产出噪声"事实"（有告警留痕，但内容不可用且用户难自查）。
- **建议修法**：解码前检测前 2 字节 BOM，命中则按 utf-16 相应端解码；顺带覆盖 UTF-32 极少见情形。

### BUG-3（P3·低）`_normalize_invisible` 删除全部 `\r`，CR-only 文件整篇折成一行

- **证据**：file_parser.py:636-639——`if ch == "\r": changed=True; continue`，注释只考虑了 CRLF→LF 归一与孤立 \r 丢弃，未考虑**整份文件以孤立 CR 为行尾**（旧 Mac 行尾）的输入。
- **触发条件**：CR-only 行尾的 .txt/.md/.csv 上传。
- **后果**：全文折叠为单行：`simple_parse_outline` 只能看到第一行（目录识别全废）、事实分段器切不出章节、CSV 退化为一行——且**无任何告警**（changed=True 只报"归一了不可见字符"）。
- **建议修法**：统计孤立 CR（后一字符非 \n）数量，超阈值时追加告警「源文件行尾为 CR，请转换后重新上传」，或按孤立 CR 还原为 \n。
