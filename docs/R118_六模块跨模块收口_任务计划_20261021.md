## 二、原则

1. **所有结论必须有代码依据（文件:行号）或测试结果支撑**。
2. **加法式改动优先**：不删既有字段、不改既有返回契约键。
3. **零迁移 / 零 DDL / 零新增依赖**；本轮**零新增配置项**。
4. 每修复项配护栏，且护栏必须能被 A/B 变异打到。
5. Windows 行尾敏感文件必须字节级读写（本轮 6 文件体检 CRLF 全 OK）。

## 三、本轮成立的三条操作规程（新增）

1. **跑基线时不并行派发探查任务** —— 并行会让聚类整片假失败（实测 58 failed → 复跑 0 failed）。
2. **判定以 pytest 摘要行为准，不以 EXIT 为准** —— 宿主机 safe-delete 守卫会污染退出码。
3. **全量假故障先单独复跑再定性**。

## 四、验证方式

- 后端：`python -m pytest -q > logs/... 2>&1`（PowerShell 管道会让退出码失真）
- A/B：`python artifacts/r118/ab_r118.py`（字节级读写 + SHA 还原校验）
- 门禁：`ruff check`、字节体检 `artifacts/r118/byte_check_r118.py`
