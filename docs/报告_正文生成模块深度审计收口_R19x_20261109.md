## 四、修复项清单（file:line 为修复后位置）

### FIX-1（P1）正文首稿重试无永久错误闸
- 现象：`_generate_first_draft` 对任何异常照常退避重试，401/402/403/404 白烧配额+超时；config `ai_retry_on_quota_error`（默认 False，注释声称已生效）在此链路**从未被读取**，与目录链（_sse_outline_review.py:285）同判据不同覆盖。
- 修复：`routers/sse_handlers.py` `_generate_first_draft` except 分支在退避计算**之前**接 `if not AI_RETRY_ON_QUOTA_ERROR and _is_quota_error(e): break`（429 限流不入闸，保持退避）。复用既有 `_is_quota_error`（:440，词边界版），零新增配置项。

### FIX-2（P1）限流判定裸子串误判（两处）
- `sse_handlers.py` 首稿重试退避基数判定 `("429" in ... or "rate" in ... or "limit" in ...)`：`"generate"/"moderate"/"word limit"` 等普通文本误入 20s 限流退避；`"context 42900 tokens"` 误判 429。
  → 新增模块级 `_is_rate_limit_text()`（`\b429\b` 词边界 + 规范关键词 rate limit/rate_limit/ratelimit/too many requests/限流），与 R190 目录侧 `_QUOTA_CODE_RE` 同纪律。
- `provider_factory.py:_status_from_error`（:3548）`"429" in err_str` 裸子串 → `_STATUS_429_RE = re.compile(r"\b429\b")`；旧实现会把 `HTTP 42980`/`42900 tokens` 误记 429，污染自适应并发窗口并触发配额冷却路径。

### FIX-3（P2）task_status DB 分支连接获取无保护
- `sse_handlers.py:task_status` 内存分支 miss 后 `conn = await get_read_conn()` 在 try 外：连接失败直接 500 且无归因——恰是断线重挂最依赖的兜底分支。
- 修复：try/except 包裹，失败 WARNING 留痕 + `HTTPException(503, "任务状态读取失败，请稍后重试")`（可重试语义），与内存分支 conn 兜底口径对齐。

### FIX-4（P2）档位字数批量 UPDATE 裸写
- `sse_handlers.py` word_budget_tier 分支 `executemany UPDATE sections SET word_budget` 不持 `_db_write_lock`、不重试，与同函数占位章落库（:2783 持锁+retry_db_op）口径不一致；WAL 锁竞争窗口下 locked 静默丢档位（仅 warning），后续章节按旧字数档生成。
- 修复：`_persist_tier_budget_once` + `async with _db_write_lock: await retry_db_op(..., max_retries=3)`。

### FIX-5（P2）首稿重试退避不响应停止/暂停
- `_generate_first_draft` 的 `asyncio.sleep(backoff)` 前后无 `wait_resume/is_stopped` 检查（对照续写循环 :4835 有）：停止后该章仍睡满 `CONTENT_RETRY_BACKOFF*2^n` 并占用信号量。
- 修复：退避前 `wait_resume(task_id)` + `is_stopped` break，退避后复检再 break（日志「跳过首稿重试退避」/「退避后终止首稿重试」）。

### FIX-6（P2）numeric_lock 围栏掩码缺口（R76 单一事实源回归）
- `numeric_lock.py` 本地 `_FENCE_RE = r"```.*?```"` 两处缺口：① `~~~` 波浪围栏完全不掩，图内数值被当正文数值比对；② 非贪婪配对对未闭合块把两块间正文整体掩掉（违规数值被隐藏）。
- 修复：`_masked_text` 改委托 `fence_common.fence_char_ranges`（行级判据：看信息串+长度容错，未闭合块延伸到文末）；删除本地正则；R76 护栏 `ALLOWED`/消费方名单同步登记 `services/numeric_lock.py`（棘轮收紧）。
- 行为实证：~~~ 掩码 / 行内 ``` 提及不再隐藏违规 / 未闭合块图内数值不再误报。

### FIX-7（P3）续写 token 折算与字数容差解耦
- `content_runtime.py:continue_max_tokens` 硬编码 `budget*1.1`，而续写循环总字数上限系数 = `1 + word_budget_tolerance`；用户改容差后两者失配。
- 修复：加法式参数 `cap_factor: float = 1.1`（默认行为逐字不变，脏值回落 1.1）；调用点传 `cap_factor=1.0 + _cont_tol`。
