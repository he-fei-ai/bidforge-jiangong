### 2.2 内容组装

- **封面**：方案名（`_display_scheme_name`）→ 编制单位 → 日期 → 信息表（`_add_cover_info_table`，`cantSplit` 防行断页）。
- **目录**：`TOC \o "1-N" \h \z \u \* MERGEFORMAT` 域 + `settings.xml` 的 `updateFields=true`（Word 打开自动刷新页码）。
- **正文**：`_parse_content_blocks` 分块（标题/段落/有序无序列表/表格/围栏代码/公式/内联图表/图片）→ 逐块渲染。
- **图表**：`[CHART_TYPE: X]` 块 + `chart_lookup` 位图；缺图时同类型兜底借用（`_resolve_chart_code`，按文档顺序取最近前一张）。
- **图题/表号**：`_figure_chapter_num` 按当前章号占号，渲染失败回退（不虚跳）。
- **附录**：全局事实表、参考资料表（`_finalize_simple_table` 统一收口）。
- **公式**：LaTeX → OMML（`docx_math.latex_to_omml` → `_add_omml_formula`）。

### 2.3 模板与页面骨架

| 项 | 实现 |
|---|---|
| 模板 | **无外部 .docx 模板**：`Document()` 使用 python-docx 默认模板，全部版式在代码中生成（封面/目录/表单/正文/附录） |
| 纸张 | 显式 A4 `11906×16838 twips`（L4767，R117 FIX-5） |
| 页边距 | 默认四边 2.5cm；`engineering` 预设 上下 2.54 / 左右 3.18cm（L3125–3130） |
| 页眉页脚 | 页眉 = 方案名；页脚 PAGE / NUMPAGES 域；`titlePg` 首页不同 |
| 章节 | `Heading 1~7` 样式 + `outlineLvl` 控制目录层级；`page_break_before_chapter` 控制章前分页 |

### 2.4 图表按需渲染与降级

- 前端已渲染位图 → 直接嵌入；未渲染 → 后端 `_prepare_export_render` 兜底渲染。
- 渲染失败 → `_write_chart_placeholder_line` 写「[图表渲染失败：…]」文本占位，**不写红字报错图**，图号回滚不占号（`_DocxBodyRollback`）。
- 图片尺寸：`_fit_image_cm`（宽度上限 16cm、高度上限 22cm、优先 PNG 300DPI 元数据）+ R127 新增「按当前节版心封顶」。

### 2.5 缓存、原子替换、并发

- 指纹三元组：`(scheme_id, config_hash, content_hash)`，`content_hash` 内含 `exporter=_EXPORTER_VERSION`。
- 命中判据：文件存在 + `size>0`（`_cache_row_viable`）+ ZIP 头 `PK\x03\x04` 与尾部 64KB 内 EOCD `PK\x05\x06`（`_artifact_intact`）。
- 落盘：临时文件 + `os.replace`；在飞注册 `_export_inflight_*` 防 GC 误删。
- 并发：同 key 去重锁；不同 key 并行；`_EXPORT_BUILD_LOCKS` 防线程池堆积。
