## 4. 修复项清单（10 项）

### FIX-1 · P1 预检↔渲染计数器 parity 破裂

- **文件**：`app/routers/_export_issue_scan.py`
- **根因**：`_detect_duplicate_sections:690` 调用 `_count_child_namespace_subheadings` 从 `_export_issue_scan` 模块全局解析；渲染端 `export.py:3810` 从 `export` 模块全局解析。测试 patch `export._count_child_namespace_subheadings` 只影响渲染端。
- **修法**：晚绑定——`_detect_duplicate_sections` 经 `app.routers.export` 模块命名空间 `getattr` 解析计数器函数，monkeypatch 渲染端 = monkeypatch 预检端。
- **验证**：17/17 全绿（基线 15p+2f → 17p+0f）。

### FIX-2 · P2 五处正文落库旁路子标题归一化

- **文件**：`review_autofix.py` / `consistency_repair.py` / `consistency_fullbook_repair.py` / `defect_ledger.py` / `repair_agent.py`
- **根因**：整章改写正文后直接 `UPDATE sections SET content=?`，未经 `normalize_section_content_subheadings` → AI 重排/重编号的子标题错号永久留库。与 `shrink_section`（R2 · 2026-11-05 已修）不一致。
- **修法**：5 处 UPDATE 前统一补 `normalize_section_content_subheadings`（幂等、受 `content_subheading_renumber` 开关控制、fail-soft 不阻断落库）。
- **验证**：review_autofix 簇 179/179 全绿。

### FIX-3 · P2 shrink 缓存失效在 commit 前

- **文件**：`app/routers/sections.py`（shrink_section 函数）
- **根因**：`invalidate_export_cache` 命中缓存行时内部 `db.commit()` → 提前释放写锁/事务（R184 同型残留）。
- **修法**：将失效移到 `db.commit()` 之后（与 `_save_outline_to_db` 的 R184 修复同口径）。
- **验证**：`test_shrink_numbering_sync_r2` 2/2 全绿。

### FIX-4 · P2 renumber 少写行 fail-soft 升级为自愈重试

- **文件**：`app/routers/sections.py`（renumber_sections_after_reorder）
- **根因**：批量回写行数不足只 WARNING，后续 `_renormalize_all_section_contents` 按陈旧编号重写全方案正文（静默放大）。
- **修法**：少写行时重读树 + 重排 + 重写（最多 2 轮），幂等操作安全收敛。仍不回滚（调用方事务内，回滚代价大于重试）。
- **验证**：`test_reorder_numbering` 3/3 + `test_outline_numbering_sync` 35/35 全绿。

### FIX-5 · P2 heading_v1 L6/L7/8 空编号拼「、」脏前缀

- **文件**：`app/services/ai/heading_v1.py`（format_heading）
- **根因**：`generate_number` 对 L6/L7/L8 返回空串，`format_heading` 仍拼 punctuation → 「、标题」。
- **修法**：空编号时直接返回裸标题，不拼标点。
- **验证**：编号簇 84/84 全绿。

### FIX-6 · P2 json_response docstring 深度防护值失真

- **文件**：`app/services/ai/json_response.py`
- **修法**：docstring「递归深度防护 20」→「与 numbering._MAX_TREE_DEPTH=200 同源」。

### FIX-7 · P2 outline_library 写路径日志补齐

- **文件**：`app/routers/outline_library.py`（apply_library_and_save）
- **修法**：套用目录库整表重建前后增加 INFO 日志（节点数、library_id、scheme_id）。

### FIX-8 · P3 OUTLINE_REVIEW/FIX_MAX_NODES 配置化

- **文件**：`app/config.py` + `app/routers/sse_handlers.py`
- **修法**：新增 `outline_review_max_nodes`（默认 150）与 `outline_fix_max_nodes`（默认 1200），与 `outline_generate_max_nodes` 口径对称。默认值与硬编码逐字相同，**向后兼容**。

### FIX-9 · P1 前端轮询覆盖未落库本地节点

- **文件**：`tests/test_logging_accuracy_20261005.py`（计数锁 14→15）+ `frontend/src/tests/outlineStoppedCkptGuard.test.ts`（正则放宽 `(` 分组）
