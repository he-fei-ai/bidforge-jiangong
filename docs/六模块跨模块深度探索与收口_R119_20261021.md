## 四、修复项清单（TD-4）

### 4.1 根因
`content_utils.strip_fenced_code_blocks()` 无 lang 区分，```markdown 围栏内部被整段剔除；导出侧 `content_blocks._parse_content_blocks()`（R117）却把同样内容递归解析成真实正文渲染进成稿。两处对「markdown 围栏内部是不是正文」结论相反 ⇒ 字数失真。

### 4.2 生产取证（`artifacts/r119/_probe_td4_wordcount.py`，只读复算）
258 章中 3 章含 markdown 家族围栏，内部正文被现口径漏计：
- `sec=9eaee667`《地基承载力特征值确定》：现口径 1636 / 漏计 1495 / 实为 3131（缺 48%）
- `sec=11ebe09e`《电梯井道墙体砌筑与抹灰》：2400 / 1861 / 4261（缺 44%）
- `sec=a0b4093e`《专职安全员现场巡查职责》：1847 / 2017 / 3864（缺 52%）

### 4.3 修法（3 文件，加法式、默认零变更）
1. **`fence_common.py`**：新增判据唯一事实源 `MARKDOWN_FENCE_LANGS = ("markdown", "md", "gfm", "markdown-gfm")`（叶子模块、零依赖；刻意不含 text/plaintext）。
2. **`content_blocks.py`**：`_MARKDOWN_FENCE_LANGS = _MARKDOWN_FENCE_LANGS_SHARED`（改为引用 fence_common 同一对象，**保留模块内旧名 ⇒ 既有引用/测试导入点零改动**，identity 已实测为 True）。
3. **`content_utils.py`**：`strip_fenced_code_blocks(content, *, keep_markdown_fences=False)` 新增**默认关闭**参数；命中 markdown 家族围栏时**只丢开/闭围栏行、保留内部正文**；其余语言逐字不变。仅 `text_word_count` 与 `_normalize_for_readable` 传 `True`。

### 4.4 向后兼容
- 默认 `keep_markdown_fences=False` ⇒ 与旧行为**逐字节一致**（B 组 `test_default_option_is_byte_identical_to_legacy` 锁）。
- 非 markdown 围栏输入 `keep=True` 与 `keep=False` 输出恒等（`test_option_only_moves_markdown` 锁）。
- mermaid/chart-json/python/text 等仍整段剔除（`test_mermaid_still_excluded_under_new_flag` / `test_text_fence_is_code_on_both_sides` 锁）。
- 未闭合 markdown 围栏仍走「从开围栏处截断」严格口径（不改判据）。

## 八、新增配置项说明

- 默认 False ⇒ 全局行为与引入前**逐字节一致**（向后兼容）。
- 仅 `text_word_count` / `_normalize_for_readable` 两处字数路径显式传 True ⇒ 影响面被局限在「字数统计口径」，不改导出、不改渲染、不改存储结构。
