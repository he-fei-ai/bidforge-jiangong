> ## 二、根因与实证
>
> ### 2.1 P1-1 跨章全熔断快速失败
>
> **R109 实证**：`_gate_candidates` 在「所有候选均熔断/配额冷却」时放行 1 个 probe 候选（既有语义「少打而不是全不打」）。多章正文生成时，每章独立调用 `chat_with_fallback` → 每章各 probe 一次 → probe 超时（`ai_fallback_attempt_timeout=120s` 或候选自带 timeout）→ 5 章空转 150-300s 后全部标 failed。
>
> **修法（模块级连续计数 + 冷却窗口）**：
> - `ALL_CIRCUIT_FAST_FAIL_THRESHOLD=2`：连续 2 次「gate 放行空候选」（usable 为空 = 所有候选被熔断/冷却/禁用/无 key）后激活
> - `ALL_CIRCUIT_FAST_FAIL_COOLDOWN=60s`：窗口内 `_gate_candidates` 顶部直接 `raise RuntimeError("全熔断快速失败…")`，不再 probe、不再发任何请求
> - 解除条件：任一 gate 放行非空候选（`_record_all_circuit_outcome(success=True)`）或 `chat_with_fallback` 拿到 winner → 立即清零
> - 判据锚点：`_gate_candidates` 的 `usable` 非空 = 成功 / 空 = 失败（probe 放行也计失败——它本身是「全熔断」形态，probe 成功后由 winner 侧清零）
>
> **为何是模块级而非任务级 Event**：全熔断是 **provider 集群级**故障（所有候选不可用），对同一进程内任何任务（正文/目录/事实/bid_analysis）都成立——模块级冷却让所有调用方同时快速失败，比任务级 Event 覆盖面正确且实现更简（无需在 sse_handlers 闭包里加 Event + 检测错误消息）。
>
> ### 2.2 P1-2 思考吞噬翻倍失败冷却
>
> **R109 实证**：`_attempt_candidate` 的 O3 纪律（`ai_retry_on_thinking_exhausted`）：思考吞噬（finish_reason=length 且正文为空）→ 翻倍 max_tokens 重试**严格一次**（1536→3072）。若翻倍后**仍**思考吞噬（4096 上限内或已达上限），旧行为是「本候选记败 → 进降级链下一候选」——而下一候选若也是推理型（sensetime 多配置 / 同型模型），会重走一遍「吞噬→翻倍→失败」，白烧 1 次完整网络往返。
>
> **修法（provider 级短时冷却）**：
> - `_note_thinking_dead(pname)`：翻倍失败（已重试过 / 翻倍前已达上限两种形态）时标记该 provider 60s 冷却（`THINKING_DEAD_COOLDOWN=60.0`）
> - `_gate_candidates` 内跳过冷却中的 provider（与配额冷却同走 `circuit_skipped` 审计口径，INFO 级日志）
> - 成功路径 `clear_thinking_dead(pname)` 即时清除（provider 恢复可用即接回，不误伤后续调用）
> - 与既有 O3 严格一次纪律互补：O3 管「同候选内翻倍一次」，R110 管「跨候选不再重复尝试同型推理模型」
>
> **为何是 provider 级而非任务级**：思考吞噬是**模型能力面**故障（该模型在 2× tokens 内仍无法产出正文），与任务无关——同进程内其它任务调用该 provider 也必然失败，模块级冷却同样受益。
>

> ⚠️ **A/B 工具教训（本轮 3 条）**：
> ① `-k` 表达式传 `Class::test` 节点会**整体 deselect**（`::` 非 -k 语法），目标用例根本未运行 → CAUGHT 判定假阴性；必须**节点 ID 直传** + 「目标用例名确实出现在输出」自检（本轮脚本首版 4/4 MISS 全为此因，改判据后 4/4 CAUGHT）。

> ③ **跨行锚点必须从源文件实际文本重建**：M2 首版手抄锚点在 CRLF 归一化后 count=0 被 SKIP；改由 `_fix_m2b.py` 从源文件按标记截取实际块生成 `repr()` 字面量后命中。

> ⚠️ **测试桩教训（本轮 2 条）**：
> ① `_gate_candidates` 直接调用会走 `resolve_disabled_providers`（DB 读）+ `_log_audit`（审计缓冲 flush）→ 测试环境挂起；必须 stub 两者（async 形态，签名是 `async def`，同步 lambda 会返回协程对象被 `in` 运算炸）。
