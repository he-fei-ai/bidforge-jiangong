## 2. 探索结果（按探索范围逐项）

### 2.1 模板管理
- 81 条模板全部经 `_reg()` 注册进唯一事实源，编辑器可改、DB 可存、审计可记录。
- `get_prompt()` DB 优先、硬编码回退；`reload_prompt_cache()` 水印感知失效，前端编辑即时生效。
- **全量渲染 81 条 → 0 残留占位符、0 异常**。

### 2.2 版本控制
- `routers/prompts.py` 的 PATCH/reset/rollback 均单事务 `BEGIN IMMEDIATE` + 事务内重读 before + `updated_at` CAS（毫秒精度 `_now_ts()`，应用层生成）+ 提交后才更新内存注册表。
- `rollbackable` 判据与回滚端点共用 `prompt_snapshot_is_rollbackable()`（单一函数，无口径分叉）。
- `prompt_audit_logs` 记录前后快照 + 指纹 + 变量集合 + 全局变更序号 version。
- 管理面 `/admin/prompts/*` 挂 `require_admin_access`（fail-closed）。

### 2.3 变量与上下文组装
- `PROMPT_VARIABLE_CONTRACTS` 集中契约表；`_apply_variable_contracts()` 套用；`check_prompt_variables()` 双向漂移校验。
- **0 漂移**。
- `_resolve_shared_keys()` 递归解析 `{SHARED_*}`，环检测 + 深度上限 4。
- `render_prompt()` 单遍替换（防二次替换）、`_format_render_value()` 处理 None/bool/list/dict/set、JSON key 不替换（`(?!\s*:)` 防篡改 JSON 示例）、可选区块整行删行。

### 2.4 提示词与 AI 调用
- 全仓 AI 调用单点接线 `provider_factory._call_provider`（出站脱敏 `redact_outbound_messages` + 注入手法扫描 `scan_outbound_messages`，默认常开）。

- 唯一直接 `.chat()` 在 `services/ocr.py:320`（图片 base64 + 固定模板，无用户文本）。

### 2.5 输出解析与校验
- 统一 JSON 通道：`collect_json_response`（生成→解析→校验→定向修复→有界重试）。
