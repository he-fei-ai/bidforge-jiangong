## 2. 根因（浏览器实测复现，两个症状均确认，控制台 0 报错）

### 根因① 侧栏一次性缓存 + 永久去重 + 零刷新通道（症状1）

`Layout.tsx::ProjectTreeMenu`：
- 仅挂载时 `loadProjects()` 一次；
- `loadSchemes` 用 `loadedProjectIdsRef` 对已加载项目**永久去重**——即便 effect 再次触发也不会重取；
- `Layout` 包裹整个 `Routes`，应用内跳转**不重挂载**该树。

⇒ 新建/删除/改名项目与方案对侧栏完全不可见，实测只有 F5 整页刷新才更新（项目级、方案级、计数、删除残留四个方向均复现）。

### 根因② 「看着能点、点了没反应」的死占位（症状2）

零方案项目的侧栏子项「进入项目新建方案」/「暂无方案」为 `disabled: true`，且 Menu `onClick` 显式排除 `/create-scheme`、`/empty` 结尾 key —— 用户表述的「点击新建方案时未能进入编辑状态」即命中此死占位（详情页的「新建方案」按钮弹窗本身实测正常，非缺陷）。

## 3. 实现细节（零后端改动、零迁移、返回契约无变化）

### 3.1 新文件 `frontend/src/utils/sidebarEvents.ts`（最小 pub/sub + 两个纯函数）

- `subscribeSidebarTreeRefresh(fn)` → 返回取消订阅（useEffect 清理）；
- `notifySidebarTreeRefresh(projectId?)`：单订阅者抛错不影响其它订阅者（fail-soft）；
- `computeRefreshTargets(loadedIds, expandedKeys, projectId)`：重取集合 = 已加载 ∪ 展开键项目 ∪ 事件目标（纯函数可测）；
- `resolveTreeClick(key)`：占位 → `/project/{id}?create=1`；loading → 无反应；其余原样放行（非字符串安全）。

### 3.2 `Layout.tsx::ProjectTreeMenu`

- 订阅总线 → `refreshTree(projectId?)`：`projectsApi.list()` 重取项目；**清空 `loadedProjectIdsRef` 后**逐个重取「targets ∪ 最新列表中所有有方案的项目」（防「别处新建的首个方案」漏取）；仅对「新出现且有方案」的项目自动展开，**不强行重开用户手动收起的项目**；拉取失败保留旧树（下一次事件再重取）；
- `projectsRef` / `expandedKeysRef` 镜像最新值（沿用 `schemesMapRef` 既有手法，避免 effect 依赖抖动重复订阅）；
- 两个占位项去掉 `disabled: true`，「暂无方案」文案改为「暂无方案 · 点击新建」；`onClick` 收敛为 `resolveTreeClick`。

### 3.3 `ProjectDetailPage.tsx`

- 五个方案写入口成功后 `notifySidebarTreeRefresh(id)`：create / duplicate / archive / update（改名）/ delete；
- `useSearchParams` 消费 `?create=1`：自动打开新建方案弹窗（进入编辑状态），并 `navigate(replace)` 清理 URL 防刷新/返回重弹；依赖 `searchParams`（已在同路由时组件不重挂载，只有查询变化能触发）。

### 3.4 `ProjectListPage.tsx`

项目新建/改名与删除成功后 `notifySidebarTreeRefresh()`（全量刷新档）。

## 5. 经验教训

1. **「一次性挂载加载 + 永久去重缓存」的常驻组件必须显式配刷新入口**：`loadedProjectIdsRef` 的去重是为治「50 req/s 打爆 SQLite」的历史缺陷而加的，但它把侧栏变成了只读快照——加缓存时必须同时回答「何时失效」。本轮以最小 pub/sub 补上失效通道，而非回退去重（两个历史缺陷都保住）。
2. **`disabled:true` 的占位项是交互陷阱**：视觉上与可点项几乎无差别，点击无反应会被用户记成 BUG。占位要么给出明确不可点样式，要么真正可用。
3. **判据下沉纯函数 + 静态接线锁**（`computeRefreshTargets` / `resolveTreeClick` + `import.meta.glob` raw 源码锁）沿用本仓既有范式：行为可单测，接线（notify 调用点数、订阅、去 disabled）由护栏钉死，日后摘除必红。
4. **撞号让号后必须全量复跑**：R90→R91 改号后重跑护栏 12 例 + tsc，均绿；PowerShell 批量重写用 `[System.IO.File]::ReadAllText/WriteAllText`（不拆分行尾）+ 无 BOM UTF-8，并以字节体检兜底。
