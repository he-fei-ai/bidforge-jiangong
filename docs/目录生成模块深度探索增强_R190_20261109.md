2. **`create_section` 的 `sort_order == 0` 哨兵**：显式传 0 被当作「未传」追加末尾——注释已声明向后兼容，改 `model_fields_set` 判定影响面大，登记遗留。
3. **`"1.1）标题"` 剥号残留全角括号**：罕见形态，核心剥号正则全仓共用，登记遗留。
4. **审核/修复阶段吞错成 `review_skipped + passed=True`**：有 `skip_reason` 留痕 + `outline_auto_confirm` 硬前置拦截 + 日志如实记录，属「宁可不审也不阻断交付」刻意取舍，维持现状。
5. **review_status 不随编号顺移重置**：拖拽重排只改子标题编号（非语义内容），重置会清掉用户已有审批；与 B-09 修复链（改号即重置）政策分叉已在代码注释留痕，待产品确认（登记）。

## 七、运维与效果复算锚

- **需重启后端**：`numbering / content_blocks / outline_versions / outline_library / sections / sse_handlers / schemes / upload_outline / prompts.outline / heading 链` 常驻。
- **前端需重建**：`SchemeWorkbenchPage / workbenchTypes / useOutlineGate / genericResidual`。
- 无需清库、零迁移、零 DDL；所有响应变化均为**加法式新键**（`title_sanitized`、`placeholder_titles_filled`、`checkpoint_failed` 语义修正、`context_degraded` 前端消费），旧客户端行为逐字节不变。
- **效果复算锚（下批日志/接口）**：
  - 正文生成中回退快照 → 409「整表恢复会与生成结果互相覆盖」；
  - 章节改名后保存 → 其正文内旧标题自引用行被改写为当前标题，其后子标题编号不错位；
  - 停止 + checkpoint 写失败 → 终态 `stopped`（非 degraded）+ `checkpoint_failed=true`；
  - 并发窗口 ≥2 时停止 → 停止点之后各单元已完成章节**仍在部分成果中**；
  - 含 "40480 tokens" 的超长上下文报错 → 不再被判配额类、走正常重试/降级链；
  - 生成中点复制方案 → 409；空标题章节沉淀目录库 → `placeholder_titles_filled≥1` 且子树保留；
  - SSE `context_degraded` → 前端 toast「上下文降级：…（被截断/装配段失败）X→Y 字」。
