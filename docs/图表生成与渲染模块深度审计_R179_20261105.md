## 3. 深度探索结论

### 3.1 生成规则与工作流

1. **正文一体生成**：提示词要求模型在撰写正文时直接内嵌图表块，配图判定=章节语义匹配触发词 → 数据可得性 → 在对应段落后加一句引导语并插入围栏（`prompts/content.py` L191–L229）。每节最多 1 个图表块，同类型全方案 ≤3 次（L225–L226）。
2. **登记**：正文生成后 `build_inline_chart_plan` 扫描围栏、推断类型、校验、去重、按配额登记；非法块走 `repair_mermaid`，修不好则删块并在 `dropped_out` 留可见记录。
3. **导出**：`_prepare_export_render` 汇总本章图表代码 → 去重 → 小并发渲染（`_chart_cache.get_or_render`）→ `write_section` 按图题规范插图并按章重排图号。
4. **前端**：预览用 `mermaidRuntime` 渲染；导出前 `renderChartsForExport` 生成 `fe_codes`（前端渲染 PNG）供后端直接嵌入，与预览所见一致。

### 3.2 图题与图号

- 规范：`图 {章号}-{序号} {图名}`。
- 图名优先级（实现顺序）：**上游显式图题** → 载荷/指令 `title` → 引导语 → 类型通用名（`content_blocks` L387/L653/L666，导出侧 `export.py` L1368 注释同口径）。
- 图号由导出侧按章连续分配；渲染失败默认**跳过且不占图号**（`export.py` L3304 起），仅 `chart_fail_placeholder=true` 时写占位并占号。
- R179 新增：图表**下方**的「图 X-Y 题名」也会被吸收（见 §5-G08）。

### 3.3 容错与降级

- 校验：`validate_mermaid`（`image_engine.py`）与 `validate_chart_payload`；修复失败删块并留 `dropped_out` 记录。
- 渲染：HTTP Mermaid Service 优先；`allow_pil_fallback=true` 时 Mermaid 载荷回退 PIL v2；`allow_pil_fallback=false`（导出默认）时不回退，失败即跳过。
- `chart_fail_placeholder` 默认 `false`（交付文档不写红字占位）。
- 无本地兜底类型（mindmap/sequence/class/state/er/journey）此前只能看 `failed` 总数，R179 新增可区分信号（见 §5-G06）。

### 3.4 缓存、去重与并发

- 进程内 LRU：`mermaid_renderer._render_cache`，键包含 `chart_type + code + duration/unit/tick + skip_http + allow_pil`，渲染器版本号在键内（`_RENDERER_VERSION=8`）。
- 磁盘缓存：`ChartCache` 以 `chart_type + 代码指纹` 为键；`get_or_render` 单飞（leader 渲染、follower 等结果），命中/未命中/坏缓存均有既有护栏。
- 导出侧按 `(chart_type, code)` 去重，受控并发渲染，避免重复计算；跨章借图计入 `fallback_borrowed`。
- 本批次修复 HTTP 成功路径不回填 LRU 的性能缺陷（见 §5-D03）。

### 3.5 配置与日志

- 配置：`chart_fail_placeholder`（默认 false）、`allow_pil_fallback`（默认 false）、`max_ai_images`（默认 0）、`BIDFORGE_CHART_CACHE_DIR`（缓存目录覆盖）。
- 日志/响应：渲染统计经 `X-Chart-Render-Stats` 返回；前端在下载后展示图表失败、甘特截断、全局事实异常等 warning。
- 本批次**未新增任何配置项**；仅加法式新增响应字段 `no_pil_fallback` / `no_pil_fallback_types`。

### 3.6 测试方式

- 单元：校验/推断/图题/围栏/缓存，集中在 `backend/tests/test_chart_*.py` 等 20+ 文件。
- 集成：`test_export_docx_smoke.py` 走真实 `export_docx` 到 DOCX 落盘；`test_chart_alarm_guard_r178` 覆盖失败告警。
- 前端：`frontend/src/tests/exportResponse.test.ts`、`exportCharts.test.ts`、`fencePreprocessR76.test.ts`、`chartTypesParity.test.tsx`。
- 本批次基线命令：仅图表域文件 + `-p no:cacheprovider`，不跑全量 pytest。

## 6. 增强与优化项

1. **编排增强（既有能力复核）**：提示词仍由 AI 自动判定配图章节、类型与插入位置，未新增人工按钮（`prompts/content.py` L191–L229）。本批次未改提示词，避免与并行提示词会话冲突。
2. **格式一致性**：图表围栏与 Markdown 正文共用同一解析器；导出侧新增的「连续管道行→原生表格」「公式切分」只作用于 `paragraph/list_item` 块，经 `_normalize_render_blocks` 复核不触碰 chart 块，图表代码不会被误伤。
3. **性能**：D-03 消除 HTTP 重复渲染；导出侧继续按 `(chart_type, code)` 去重并受控并发。
4. **可观测性**：G-06 让「无本地兜底」失败从总数中可分离，前端文案可执行。
5. **语义完整性**：G-08 保留作者显式图题，图号仍由导出侧统一重排，不产生「图 3-1」与重排号冲突。
