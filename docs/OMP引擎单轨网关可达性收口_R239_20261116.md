## 六、本轮教训归档

1. **「全量 pytest 前必须先跑收集期校验」**：本轮首次全量跑出 977 errors，追查后发现是 sse_handlers.py 损坏所致。正确做法：每次改动后先 `python -m pytest tests/ --collect-only -q` 确认收集期零错误再跑全量。
2. **GBK 编码污染比行尾损坏更隐蔽**：行尾损坏（CRLF→LF）byte 体检能抓；编码错乱（GBK 替换为 `?`）需要实测 `b.decode('utf-8')` 才能发现。**判据：改完 .py 文件后必须 import 一次目标模块**。
3. **`engine_policy().fallback` 与 agent_engine 单轨语义是分层的不同概念**：前者描述「omp 挂起时可以试哪条后备引擎」（引擎层决策），后者描述「单次执行失败的收敛形态」（执行层决策）。混淆两者会导致护栏断言写错（首轮 `assert ec["fallback"] is None` 即因此失败）。**解决：docstring 显式区分两层语义**。
4. **docs/ 批量删除是不可逆损伤**：239 个文档文件被清空后无法通过 git 恢复（git 跟踪的 blob 仍在，但工作树文件已被 `remove` 且未 staged）。后续 cleanup_guard.ps1 的 `-Mode Shutdown` 模式须把 docs/ 加入保护区。
