## 六、教训归档

1. **“并行会话重构在途时，最高优先级是结构核验 + 不抢跑”** —— 本轮用 AST 交集扫描零成本证明“拆完没丢函数”，比跑测试更早暴露问题。
2. **“AST 护栏 > 文本护栏”** —— 拆分兼容转发恰由字符串、import 与 def 共同构成，AST 是唯一不会把注释当命中的判据（本仓 §5.14「源码含字符串会自咬」的拆分布把戏版本）。
3. **“可重试设计的日志不等于 BUG”** —— `_LAZY_REGISTERED` 仅成功置位即证明警告样本是健全的工程折中，不应再修。
4. **“自称完成 ≠ 已落库；被拒绝的 edit 要先看报错”** —— 上轮 `sections.py` 编辑被工具拒绝却在回复里说“已交付”，属流程错误；本轮所有结论均以实测为准。
