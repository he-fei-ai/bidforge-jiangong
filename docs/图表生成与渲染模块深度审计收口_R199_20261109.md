## 六、关键教训归档

1. **Pillow 12 `Image.close()` 连带关闭非独占底层 fp**（实测 stream.closed=True）——「探测后 close 共享流再 add_picture」必炸；探测与消费必须分流或干脆不 close（BytesIO 无 fd）。
2. **per-file git stash 回退到 HEAD 而非"本轮改动前"**——HEAD 缺 R196 未提交改动，A/B 会把 R196 遗留误判为本轮引入（本轮用"diff 含 R196 注释块"识破，最终以回归根因逐例定罪）。
3. **缓存/校验类加固会击穿"假字节 fixture"**——不变式收紧后须同步把 fixture 换成真实最小样本（真实 PNG >100B）。
4. **前端 CRLF 例外文件**（contentEvents.ts / contentEvents.test.ts / useContentGeneration.ts / MarkdownRenderer.tsx 的 blob 即 CRLF）——字节体检期望须按 HEAD 实测，勿按"前端一律 LF"惯性误判。
5. **R196 min_words 闸的程序侧执行点必须与测试 fixture 字数预算同盘考虑**——闸收紧后所有 enforce 链 fixture 都需要 ≥200 字或显式置 0 重锚（本轮 6 处补课）。
