## 0. 摘要

固定 `id='primary'`），与同仓文本模型配置模块（R248/R249 已成熟：多模型表、
场景路由表、配置审计表、密钥三态、多环境、熔断器、缓存代际号、降级链）相比，
存在明确的功能缺口与技术债。本轮聚焦落地 **5 项**（均先行为实证定罪）：

| 编号 | 优先级 | 缺口 | 落地 |
| --- | --- | --- | --- |
| IM-1 | P1 | 图像配置保存未做 Base URL 校验 / SSRF 防护 | 保存路径复用 `normalize_base_url`（协议 + 域名 + 内网拦截 + `AI_ALLOW_PRIVATE_BASE_URL` 逃生） |
| IM-2 | P1 | 缺乏「按业务场景路由图像模型」 | 新增 `image_scene_routes` 表 + `resolve_scene_image_config` + 引擎 scene 感知 |

### 2.3 配置项现状

- `provider` / `model` / `base_url` / `api_key_encrypted` / `enabled`（开启生图）/
  `default_size`（1K-4K）/ `concurrency`（1-8）/ `price_per_image` / `max_ai_images`（全局预算）。
- 缺失：`default_params`（分辨率/采样步数/CFG/负面词/风格预设）、`env`（多环境）、
  `is_default`（多模型默认标记）、`status`（active/disabled）、`priority`、`remark`。

### 2.4 数据加密方案

- `services/crypto.py`：Fernet（AES-256）加密 `encrypt_api_key` / `decrypt_api_key`；
  密文以 `ENC:` 前缀存 `api_key_encrypted`。
- 密钥三态缺口：GET 只回 `has_key`（布尔），无 `key_hint`（后 4 位）与 `key_broken`
  （密文存在但解不开）标记 —— 与文本模型模块 `get_config` 的三态脱敏不同源。

### 2.5 模型路由现状

- `route_visual_strategy` 已实现三态决策（structured/illustration/none），
  但**不选模型** —— 无论「工程图示」还是「实景图」都走同一条 primary 配置 + 硬编码降级链。
- 缺失：`image_scene_routes` 表与 `resolve_scene_image_config`；无法实现
  「工程示意图路由到擅长线条的模型、实景图路由到擅长真实感的模型」。

### 2.6 安全与权限现状

- 加密存储已有；但 `image_config.py` 的 `PUT` 保存 `base_url` **未做任何校验**
  （无协议限制、无域名校验、无 SSRF 内网拦截）—— 与文本模型模块
  `provider_factory.normalize_base_url`（R175 已含 SSRF）不同源。
- 缺失：配置查看/修改/调用的审计日志（无 `image_config_audit_logs` 表）。

### 2.7 容错与配额现状

- 硬编码降级链（`["qwen_image","dashscope","agnes"]`）+ 成功/失败缓存；
  无熔断器（连续 429/5xx 自动短路）。
- 配额：`max_ai_images` 全局预算（G2 分段择优）已有；无日限额/项目限额。

### 2.8 接口与数据结构现状

- 数据结构：单行 `image_model_config`；缺失 `image_config`（多行）、
  `image_scene_routes`、`image_config_audit_logs`。
- 路由：`/api/v1/image-config`（GET/PUT/test）；缺失
  `GET/POST/PUT/DELETE /api/v1/image-models`、`POST /api/v1/image-models/{id}/set-default`、
  `GET/PUT /api/v1/image-models/scene-routes`。

## 3. 缺口与技术债清单

### 3.1 已定罪并修复的缺口

| 编号 | 优先级 | 缺口 | 影响 | 证据 |
| --- | --- | --- | --- | --- |
| IM-1 | P1 | 图像 Base URL 无 SSRF 防护 | 配置保存可指向内网/回环/云元数据，运行时请求 SSRF | `image_config.py` PUT 无 `normalize_base_url`；护栏 PUT `http://127.0.0.1:8080` → 400 |
| IM-2 | P1 | 无场景路由 | 工程图示与实景图共用一条模型，无法按场景分模型 | 无 `image_scene_routes` 表；护栏 `resolve_scene_image_config` 场景命中/未命中/删除三态 |

| IM-4 | P2 | 无多模型多配置 | 只能维护一条，无法按场景/业务隔离配置，无热更新代际号 | 表单行 `id='primary'`；护栏 `/image-models` CRUD + set-default + 缓存失效 |
| IM-5 | P2 | 无自定义生图参数模板 | 分辨率/采样步数/CFG/负面词/风格无法持久化并注入 | 无 `default_params` 列；护栏 default_params 解析 + 注入适配器 payload |

| 编号 | 优先级 | 说明 | 处置 |
