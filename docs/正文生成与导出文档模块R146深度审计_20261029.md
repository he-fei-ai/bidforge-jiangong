## 二、六类标准统一方案（t4）

六类标准的**唯一事实源**为 `backend/app/services/content_format_contract.py`。
提示词（`services/ai/prompts/content.py`）、正文自检（`sse_handlers`）、导出前体检
（`export.audit_content`）、导出渲染（`export._build_docx_sync`）一律引用同一常量，
禁止复制字面量。

| 类别 | 标准 | 实现位置（唯一事实源 → 消费方） | 状态 |

| 文字 | 标题黑体、正文宋体（备选仿宋）、西文 Times New Roman；标题不倾斜、既黑色；禁止内联格式 | `FONT_HEADING_EAST_ASIA/FONT_BODY_EAST_ASIA/FONT_LATIN` → `export._DEFAULT_HEADING_STYLES`、`Normal` 样式、`_set_run_font` | 已具备 |
| 符号 | 中全角/英半角；列表必须标准 Markdown；特殊符号 Unicode；禁控制字符/西里尔/GBK 乱码 | `_MANUAL_LIST_RE`/`_MD_LIST_RE`/`_CONTROL_CHARS_RE`/`_CYRILLIC_RE`/`_MOJIBAKE_TOKENS` | 已具备 |
| 公式 | LaTeX 统一输入 → OMML；复杂公式降级图片；编号与章节关联 | `docx_math`（OMML → PNG → 原文三级降级） | 已具备 |

## 四、图表商业级增强（t5）

已具备的四步编排（代码取证）：

1. **定类型/数据/位置/优先级** —— `_chart_pipeline` 7 类白名单（`flowchart / gantt /
   architecture / labor / comparison / layout / timeline`）；配额「每叶子小节 1 图、
   同类型全方案 3 图（`ai_image` 6）」。
2. **生成源码/载荷** —— mermaid 源码围栏 + chart-json 数据载荷（`chart_payload.extract_chart_payload` 唯一解析器）。
3. **校验语法/类型/数据** —— `_MERMAID_TYPE_MAP` + `_JSON_VALIDATORS`（7 个专用校验器，
   `comparison` 走 `validate_comparison_data`）；本轮把 `type` 白名单前移到**正文自检**。
4. **按需渲染 + 失败降级** —— 前端 mermaid.js（所见即所得）→ 后端 HTTP 服务 →
   PIL v2（`mermaid_architecture` 实测 300dpi / 154KB）；失败**跳过不占号**。

质量项（实测取证）：`MIN_IMAGE_DPI=150`，`_read_image_dpi` 低于阈值只 WARNING 不阻断；
`_fit_image_cm` 按元数据换算物理尺寸适配 A4 版心；配色走 PIL v2 稳重色板；
中文乱码无命中（日志 0 条）。

**图号规则**（`export` L5584-5590 + `_figure_chapter_num` + `_strip_leading_figure_number`）：
`图{章号}-{序号} {图名}`；图名优先级 **载荷 title > Mermaid title > 引导语 > 类型通用名**；
`_chart_ok` / `_image_format_supported` 判定在**占用图号之前**，失败即跳过不占号。

**本轮改动**：仅「类型校验口径」——契约与登记侧统一到 `PIL_RENDERABLE_CHART_TYPES`，
不新增渲染逻辑、不改配额（配额为刻意设计）。

## 五、导出渲染增强（t6）

### 5.1 数据流（现状）
`大纲 + 配置 → 章节统计 → Markdown 转 HTML/块解析 → 图表预渲染 → DOCX 构建 → 打包`
（`_prepare_export` → `_prepare_export_render` → `_build_docx_sync`）。

### 5.2 格式配置层（已具备）
- 页面：A4 21×29.7cm（`_build_docx_sync`）。
- 逐级标题：`Heading 1..9` 字号/加粗/黑色/不倾斜/`keep_with_next`/段前段后；
  `w:eastAsia=黑体`，删除 `asciiTheme/hAnsiTheme/eastAsiaTheme/cstheme` 四个主题属性
  （否则主题字体会覆盖显式字体 —— 这是「字体回退」的历史根因）。
- 7-9 级：显式 `get_or_add_outlineLvl()`（注册自定义样式并写 `outlineLevel`）。
- 编号：`numbering.py` 统一重排 + 展示态口径（`"3"→"第三章"`、`"3.2"→"2"`）。
- 表格/图片：`Table Grid` + 表头底纹 `B6B1D1` + `tblHeader` / `cantSplit`；图片 `_fit_image_cm`。
- 模板库：`_DEFAULT_HEADING_STYLES` 可整体替换（保存复用）。

### 5.3 导出后校验（已具备 + 本轮加厚）
1. 读回 `.docx`：`export_validate.validate_document` → `markdown/html/entity/placeholder_residue` + `outline_map`。
2. `docx_namespace.check_docx_file` → `ns_clean/ns_issues`（只读，不改文件）。
3. 标题映射页码回填导航：`outline_map(level,text)` + TOC 域 + `updateFields`。
4. 文件结构完整性：zip 重写后 `testzip()` + lxml 解析（护栏 `test_r144` D 组 / `test_r145` C 组）。

**本轮加厚**：导出前置 `auto_fix_table_separators`（读服务端 `settings.content_autofix_table_separators`，默认开启），并在 `test_r146`
新增「缺分隔行 → 修复 → 解析 → 渲染 → `validate_document` 残留 0」端到端断言。

**R117 回归修复（R146 收口期发现）**：`_add_table_from_markup` 中「通栏标题带合并」与
「表头前短行 gridSpan」的执行顺序被 R145 颠倒 —— 标题带（仅首格有内容）恰好也是短行，
被短行逻辑先并成 1 个 `tc`，`_merge_table_title_band` 的幂等判据随即判 False，导致
`w:tblHeader` 落回标题带（翻页重复空色带、列名永不出现）且合并格只有首列宽。
已把标题带合并**前置**，短行 gridSpan 仅在未合并时执行（`test_r117` C2 组 6 例恢复全绿）。

### 5.4 Word 2010+ 规避（已具备，`docx_namespace.py`）
- 根元素仅保留 `w/r/wp` 等 Transitional 命名空间；`w14/wp14/w15/w16*/wpg/wps/wpc/wpi` 声明**按引用判定**后删除（仍被引用的前缀绝不删）。
- 删除 `w14:paraId/textId/anchorId/editId/attributeTrackingId`、`settings` 的 `w14:docId/defaultImageDpi`。
- `mc:Ignorable` 同步剔除；空则整属性删除；`xmlns:mc` 无引用时一并删除。
- 实测日志：7 部件、2 属性清理完成；`check_docx_file` 只读校验 `clean=True`。

### 8.1 新增配置说明（默认行为与兼容性）

| 配置项 | 位置 | 默认 | 行为 | 回退方式 |
|---|---|---|---|---|
| `content_autofix_table_separators` | `app/config.py`（Settings，服务端） | `True` | 生成侧落库前、导出侧体检前执行 `auto_fix_table_separators` | 置 `False` → 两侧均不执行，正文/产物与引入前逐字一致 |
| 既有 `auto_fix_unclosed_fences` / `auto_rewrite_content` | 导出请求体 config | `False`（**保持不动**） | 未改动，向后兼容 | — |

> 定向决策：表格分隔行补齐**不**做成导出请求体配置项 —— 它是确定性纠错（不是版式选项），
> 且 `_EXPORT_CONFIG_KEYS` 的每个键都必须在导出 UI 有落点（`test_export_closeout::
> TestFrontendBackendConfigParity`）。因此导出侧与生成侧共用同一个服务端开关，
> 避免「后端新增开关却无人能设置」与「开关不失效缓存」两类既有护栏红灯。

**兼容性**：新函数确定性、幂等、无损（只在表头后**插入**一行分隔符，其余字符不动；
围栏块内不动；已含分隔行的表（含 R145 标题带形态）不动）；`False` 时为逐字回退。

### 8.2 数据结构定义（新增/使用中的契约结构）

```python

{
  "checked": bool, "passed": bool,
  "error_count": int, "warning_count": int, "advisory_count": int,

  }],

}
```

### 8.3 格式契约说明（一句话版）

> 同一份正文，在三处执行**同一份**判据：生成后自检（可观测）、导出前体检（可拦截）、
> 导出后读回（可验证）。任何一端出现「第二份判据」即由护栏测试判红
> （`test_r144::test_second_layer_reuses_single_criterion`、`test_r146::test_chart_json_type_whitelist_is_single_source`）。
