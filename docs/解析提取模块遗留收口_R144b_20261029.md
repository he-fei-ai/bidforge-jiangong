1. 新增模块级 `class ParseTargetGoneError(Exception)`；
2. `_persist_parse_result` 0 行 → `raise ParseTargetGoneError(doc_id)`（`safe_rowcount(cur) < 1` 判据不变）；
3. `_persist_parse_result_with_retry` **无需改动** —— 只对 `False` 退避重试，异常直接穿透（结构性失败不重试，语义自洽）；
