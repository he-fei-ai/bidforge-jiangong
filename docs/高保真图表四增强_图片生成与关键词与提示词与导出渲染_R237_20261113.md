## 五、教训归档

1. **「新文件行尾」要主动对齐既有惯例**：新建生产源 `.py`/`.html` 默认 LF，但仓库
   惯例「生产源纯 CRLF / 新测试与文档纯 LF」—— 写盘后需显式转换，R57 字节普查只查
   BOM/ruff/重复定义，**不查 CRLF**，故行尾对齐要靠本轮自查（bytecheck 脚本是手工的）。
2. **`.format()` 遇 CSS 花括号是潜伏运行时缺陷**：`'...{font-family...}'.format(x)` 把
   CSS 花括号误判为占位符 → 未在测试路径覆盖时（font_dir 缺省 None 不触发）静默通过，
   一旦注入字体目录即 ValueError。修复为字符串拼接，且新增字体兜底直测（缺目录返回空串/
   有目录返回含 `CJK` 与 `file:///`）。
3. **护栏断言要与实现同口径**：初版测试断言 `detect_chart_type` 返回 `org_matrix/flow_complex`，
   实测实现返回**既有类型词汇** `architecture/flowchart`（符合「不另立第三套词汇」决策）——
   断言按实现修正，而非改实现迁就断言。`detect_chart_type_with_rules` 返回字段是
   `{type, trigger, negative_hit}` 而非 `{route, excluded}`，同理修正。
4. **并行会话新增文件的静态缺陷不属本轮回归**：`executors.py` F401 是并行轮在途新增，
   初判「不修（避免跨会话冲突）、登记为并行轮收口项」；后经用户「剩余未修项修复加固」
   指令**修除**（删除未使用导入，一行、纯逻辑无改），R57 复跑全绿 —— 边界：跨会话文件
   的**确定死代码**（未使用导入）可在用户授权下最小介入，但**逻辑改动**仍须让渡给归属会话。
